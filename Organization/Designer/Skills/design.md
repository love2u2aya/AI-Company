# Designerスキル：グラフィック制作

## サムネイル制作フロー

### Phase 1：ラフ案（Day 1 中・社長承認①前）
1. Plannerから企画書を受け取る（企画書と同時に連携される）
2. 各企画案のサムネイルラフを1〜2案ずつ制作（完成品不要・判断できる精度でOK）
3. `AgentOutput/サムネイルラフ_YYYYMMDD/` に保存
4. 秘書に提出 → 社長がサムネのインパクトで企画GO/NGを判断

### Phase 2：本番制作（社長承認①後）
1. GOが出た企画のサムネイルを本番クオリティで2〜3案仕上げる
2. `AgentOutput/サムネイル案_YYYYMMDD/` に保存
3. 完成動画とセットで秘書に提出 → 社長承認②で **採用案と予備案（2番手）** を選んでもらう
4. 採用確定版と予備版を `FinalOutput/` に格納
   - 予備版は公開90分の初速が不調だったときの差し替え用（`Workspace/チャンネル運営の鉄則.md` 鉄則⑤）
   - 予備版は採用案と「切り口」を変える（例：採用＝数字直撃型 → 予備＝感情・顔アップ型）。色違い程度では差し替えの意味がない

## 高CTRサムネイルの原則

- **人物の顔**: 驚き・喜び・怒りなど感情が出ている顔写真を使う
- **文字数**: 10文字以内、大きく、太く
- **色**: 背景と文字のコントラストを強くする（黄色×黒 など）
- **余白**: 詰め込まず、視線が一点に集まる構図にする

## 使用ツール

| ツール | 用途 |
|---|---|
| ChatGPT（GPT-image-2） | サムネイル画像のAI生成 |

> **制作スタイル**: ChatGPTのGPT-image-2でサムネイル画像を生成。プロンプトで構図・色・文字配置を指示して出力する。

## 成果物の置き場所

予備版 → `Workspace/Output/FinalOutput/サムネイル_YYYYMMDD_タイトル_予備.png`
