# 社長（あなた）

パパママ社の代表。すべての意思決定者。

## 指揮系統

```
社長（あなた）
    ↓ 命令・方針を伝える
   秘書
    ↓ 解釈・タスク分解・割り振り
  各メンバー（Planner / Creator / Editor / Designer / SNS_Manager）
```

## 社長の使い方

1. やりたいこと・目標を秘書に伝える
2. 秘書が各メンバーへ指示を出す
3. 成果物は `Workspace/Output/` に集まる
4. 最終確認・GOサインを出す

## 会社の方針

- **事業**: 動画配信の広告収益で稼ぐ
- **目標**: バズる動画を継続的に量産し、広告収益を最大化する
- **スタイル**: 小さく速く。全員がプレイヤー。
