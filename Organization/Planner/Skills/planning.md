# Plannerスキル：企画立案

## 企画フロー

1. トレンドワードをリサーチ（YouTube / TikTok / X）
2. 競合の人気動画を分析（再生数・コメント・構成）
3. ネタを3〜5案出してリスト化
4. 各案に「タイトル案」「構成概要（冒頭30秒・本編・オチ）」を添付
5. 秘書に提出 → 社長GOで制作フェーズへ

## バズ企画の判断軸

- **共感**: 「あるある」「自分も思ってた」と感じるか
- **驚き**: 「えっ？」と思わせる意外性があるか
- **有益性**: 「これ知らなかった」という情報価値があるか
- **感情**: 笑い・感動・怒りなど感情が動くか

## ジャンル特有の企画指針（投資・老後資産・年金）

**ターゲット**: 50〜60代・老後直前世代（年金・資産に不安がある層）

### 刺さるテーマ
- 「年金〇万では足りない」系の危機感訴求
- 「退職金の正しい使い方／やってはいけない運用」
- 「60歳からでも遅くない〇〇」という希望提示
- NISAや新制度の「要点だけ3分で解説」
- 「実際いくら必要か」シミュレーション系

### 避けるテーマ
- 短期・高リターンを煽る投機的な内容
- 専門用語多用の難解な解説
- 若者向け積立NISAのみに特化した内容

### 企画の型（優先度順）
1. **危機感→解決策型**: 「〇〇では老後破綻する理由と対策」
2. **ランキング型**: 「やってはいけない資産運用ワースト3」
3. **シミュレーション型**: 「退職金2000万の運用を試算してみた」
4. **ニュース解説型**: 「〇〇制度、50代が知るべきポイントだけ解説」
5. **入門型**: 「NISAを今から始める55歳のリアルなやり方」

## 使用ツール

| ツール | 用途 |

| Notion / スプレッドシート | 企画書・ネタストック管理 |
| LINE | 社長への報告・確認 |

## 企画書の必須記載事項

動画フォーマット（答え先出し→深掘り型・15分）に合わせて以下を埋める：

```
【タイトル案】（3パターン）
【結論（0:00に言う一言）】
【理由①②③の見出し】
【小さな驚きのネタ（各パートに1つ）】
【やってはいけないこと（締め用）】
【次回への橋渡しネタ】
【サムネイルコンセプト案】
```

## 成果物の置き場所

企画書 → `Workspace/Output/AgentOutput/企画_YYYYMMDD_タイトル.md`

## さやか007型・突き抜けTTPチェックリスト（バズ狙い動画では必須）

参照: `Workspace/動画フォーマット.md` の「さやか007型・突き抜けTTPチェックリスト」

バズ狙い動画の企画書には、以下の10項目を○/×で**必ず自己採点**し、企画書末尾に添付すること。Criticは1項目でも×なら差し戻し。

```
【さやか007型TTPセルフチェック】
[ ] 1. タイトル4点盛り（旬KW×希少な切り口×損失額×負の命名×解決の約束）
[ ] 2. 市場の空白宣言（「誰も教えていない◯◯」とフックで明言）
[ ] 3. 二段ロケット構造（技術編→失敗談→マインド編）
[ ] 4. オリジナル命名3個以上（◯◯の呪い／◯◯マシーン／心の◯◯／◯◯資金 等）
[ ] 5. 常識の逆張り3回（各章で「世間はAだが実はB」）
[ ] 6. 失敗談の3点セット（行動描写×固有金額×当時の心の声）
[ ] 7. 数字に出典1個（大学／歴史的事象／統計）
[ ] 8. 中盤に仮想Q&A（「Q: ◯◯と不安です」を1つ挿入）
[ ] 9. 引用されたい一行（後半に名言／サムネに使える強度）
[ ] 10. 低コストCTA（コメント欄に絵文字1個指定）
```

**運用ルール**:
- バズ狙い動画 → 10項目全て○必須
- シリーズ第N弾 → 命名（4）と一行（9）のみ必須
- ロングテール型 → 適用外（戦略が異なる）
