# SNS_Managerスキル：SNS運用・広告管理

## A/Bテスト方針

| 対象 | 方針 |
|---|---|
| タイトル | **Plannerが出した3案をすべてYouTubeのタイトルA/Bテスト機能に登録する** |
| サムネイル | **A/Bテスト機能は使わない。Designerが1案に絞ったものを使う**。ただし社長承認②の2番手を「予備サムネ」として確保し、公開90分の初速が不調なら差し替える（鉄則⑤） |

## 投稿フロー

1. Editorから完成動画を受け取る
2. 各プラットフォーム向けに説明文・ハッシュタグ・タグ・**固定コメント文案**を作成
3. **18:00（日本時間）固定** で予約公開を設定（`Workspace/チャンネル運営の鉄則.md` 鉄則④）
4. 公開と同時に固定コメントを投稿・ピン留め（鉄則③）
5. 18:00〜20:00はコメントに即レス、以降も24時間以内に全件返信（鉄則②・`コメント返信運用.md`）
6. **公開直後90分（18:00〜19:30）の初速を監視**し、19:30に判定 → 不調なら予備サムネに差し替え（鉄則⑤・下記「初速モニタリング」）
7. 投稿後48時間の数値（再生数・CTR・視聴維持率・コメント数）をモニタリング
8. 分析レポートを `AgentOutput/` に提出

## 初速モニタリング（公開直後90分・鉄則⑤）

判定基準・タイムラインは `Workspace/チャンネル運営の鉄則.md` 鉄則⑤ に従う。

### 手順
1. 公開前に、採用サムネと **予備サムネ（社長承認②の2番手）** の両方を手元に用意する
2. 18:00公開後、YouTube Studio →「アナリティクス」→ 動画を選択 →「リアルタイム」を開いておく
3. 18:30・19:00・19:30 に以下を記録する
   - 再生数（累計）
   - 「通常の動画との比較順位」（例：3/10）
   - インプレッションのクリック率（表示されていれば）
4. 19:30 に判定表で「好調／普通／不調」を決める
5. 不調 → 予備サムネに差し替え（Studio →「詳細」→ サムネイル変更）→ 21:00 に再判定
6. 結果を秘書に報告し、記録を残す

### 記録フォーマット

保存先：`Workspace/Output/AgentOutput/初速レポート_YYYYMMDD.md`

```markdown
# 初速レポート｜YYYY-MM-DD｜[動画タイトル]

| 時刻 | 再生数 | 比較順位 | CTR | メモ |
|---|---|---|---|---|
| 18:30 | | | | |
| 19:00 | | | | |
| 19:30 | | | | |
| 21:00（差し替え時のみ） | | | | |

- 基準（直近10本の90分再生数の中央値）：XXX回
- 19:30 判定：好調 / 普通 / 不調
- サムネ差し替え：なし / あり（A → B）
- 所見：
```

あわせて `Workspace/Output/AgentOutput/初速記録.md`（全動画の一覧表）に1行追記する：

```markdown
| 公開日 | タイトル | 90分再生数 | 比較順位 | 判定 | 差し替え |
|---|---|---|---|---|---|
```

## 広告収益改善の指標

| 指標 | 目標値の目安 |
|---|---|
| CTR（クリック率） | 5%以上 |
| 視聴維持率（平均） | 40%以上 |
| インプレッション数 | 毎月前月比110%以上 |

## スポンサー対応フロー

1. 問い合わせを受けたら秘書に報告
2. チャンネルの数値資料（媒体資料）を準備
3. 条件・納期を交渉 → 社長に最終確認
4. 契約内容を `FinalOutput/案件_YYYYMMDD.md` に記録

## 日次報告フォーマット（LINE）

毎日1回、以下をLINEで社長に送る：

```
【日次レポート】YYYY/MM/DD

📊 前日の再生数: XX,XXX 回
👥 登録者数: X,XXX人（前日比 +XX人）

🔥 今日のトレンド:
・〇〇〇〇（急上昇ワード）
・〇〇〇〇（関連ネタ）

⚠️ アラート: （あれば）急落 or 急上昇した動画タイトルと理由
```

## 週次トレンドリサーチ（競合チャンネル調査）

毎週月曜日に実施し、結果を `AgentOutput/トレンドストック_YYYYMM.md` に追記する。
Plannerに共有することで、企画の方向性とネタの鮮度を高める。

### 調査対象
- 登録者1万〜10万人規模の「小〜中規模チャンネル」を中心に見る
  （大手チャンネルのバズは再現しにくいため参考程度にとどめる）
- ジャンル：投資・老後資金・年金・節税・FP系

### 調査項目

| 項目 | 内容 |
|---|---|
| チャンネル名・登録者数 | 規模感を把握 |
| 動画タイトル | どんな言葉・切り口が刺さっているか（**流行りのタイトルの型を抽出し `タイトル流行りストック_YYYYMM.md` に記録**） |
| 再生数・公開日 | 何日でどれだけ伸びたか |
| サムネイルの特徴 | 色・文字量・構図・感情訴求の方向性 |
| コメント欄のトレンド | 視聴者が何に反応しているか |

### ストックファイルの記録フォーマット

```markdown
## YYYY-MM-DD 週次リサーチ

### 今週のバズ動画（上位3〜5本）

| チャンネル（登録者数） | タイトル | 再生数/公開日 | 伸びた理由（仮説） |
|---|---|---|---|
| ○○チャンネル（2.3万人） | 「〜」 | 12万回/3日前 | タイトルの数字×損失回避 |

### 今週のトレンドキーワード
- 急上昇ワード：
- 注目の切り口：

### Plannerへの共有メモ
（この週に企画に使えそうなネタ・角度を1〜3行で）
```

### タイトル流行りストックの記録フォーマット

保存先：`Workspace/Output/AgentOutput/タイトル流行りストック_YYYYMM.md`

```markdown
## YYYY-MM-DD 週次（直近2週間で伸びたタイトル）

| 型の名前 | 実例タイトル（チャンネル・再生数） | 使える場面 |
|---|---|---|
| 「〇〇な人の末路」型 | 「退職金を一括で受け取った人の末路」（○○ch・15万回） | 失敗回避系 |
| 数字直撃型 | 「月3万で985万円」 | シミュレーション系 |

### 今週の流行りワード・記号
- 語尾：「〜が判明」「〜は損です」
- 記号：【】／｜／？
```

### Plannerへの共有タイミング
- 毎週月曜日にストックファイルを更新後、秘書経由でPlannerに通知
- Plannerは企画作成時に必ずこのストックファイルを参照する

## 使用ツール

| ツール | 用途 |
|---|---|
| YouTube Studio | 投稿・アナリティクス確認・収益管理 |
| YouTube Analytics API v2 | 再生数・CTR・視聴維持率・トラフィックソースの自動取得 |
| YouTube Data API v3 | 動画メタデータ・高評価数 |
| LINE | 投稿完了・数値レポートを社長に直接報告 |

> **API計測の詳細手順** → `Skills/analytics_api.md` を参照。ロングテール動画の生死判定もここで行う。
