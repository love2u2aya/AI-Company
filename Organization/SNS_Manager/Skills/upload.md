# SNS_Managerスキル：YouTube非公開アップロード

## 前提

QCからPASS通知を受け取るまでアップロードを開始しない。
**QC PASS → アップロード → 社長確認URL発行 → 承認後に公開** の順序を厳守する。

---

## アップロード前の準備（QC PASS通知と同時に確認）

QCレポートに「PASS」が記載されていることを確認後、以下を手元に揃える：

- [ ] 完成MP4（`FinalOutput/動画_YYYYMMDD_タイトル.mp4`）
- [ ] サムネイル画像（Designerが作成した採用サムネイル）
- [ ] メタデータ（QCが確認済みの草案）
  - タイトル
  - 概要欄（チャプター・参考資料・免責事項含む）
  - タグ（10〜15個）

---

## アップロード手順

### Step 1：YouTube Studioで動画をアップロード

1. YouTube Studio（studio.youtube.com）にログイン
2. 「作成」→「動画をアップロード」
3. MP4ファイルを選択してアップロード開始
4. プライバシー設定を **「非公開」** にセット（重要：公開・限定公開にしない）

### Step 2：メタデータを入力

| 項目 | 内容 |
|---|---|
| タイトル | QC確認済みのタイトルをそのまま入力 |
| 説明 | 概要欄テンプレートを貼り付け（チャプター・参考資料・免責事項） |
| タグ | カンマ区切りで入力 |
| カテゴリ | 「ハウツーとスタイル」または「教育」 |
| 言語 | 日本語 |

### Step 3：サムネイルをアップロード

「カスタムサムネイル」からDesignerが作成したファイルを設定する。

### Step 4：エンドカード設定

動画末尾20秒に以下を設定：
- 関連動画カード × 2本（チャンネル内の関連動画を選択）
- チャンネル登録ボタン × 1

### Step 5：チャプターの確認

概要欄のチャプター記述（`0:00 〇〇〇〇` 形式）を入力後、
YouTube が自動でチャプターを認識しているか動画プレビューで確認する。

### Step 6：非公開のまま保存

すべての入力が完了したら **プライバシー設定が「非公開」のまま** 「保存」をクリック。

---

## 社長確認用URLの発行

アップロード完了後、以下の形式で秘書に報告する：

```
【非公開アップロード完了】

動画タイトル：〇〇〇〇
非公開URL：https://youtu.be/XXXXXXXXXXX
確認期限：YYYY-MM-DD HH:MM まで

確認ポイント：
・内容・クオリティに問題がないか
・サムネイルを最終決定してください（候補：[ファイル名]）
・公開タイミングの確認

GO → 秘書経由でSNS_Managerに公開指示をください
修正 → 該当箇所とコメントをお伝えください
```

---

## 公開処理（社長承認後）

社長から「GO」の指示を受けた後：

1. YouTube Studio で該当動画を開く
2. 「公開設定」→ 「公開」または「スケジュール設定」に変更
3. 公開日時を設定する場合は最適な投稿時間帯を選択
   - 推奨：火〜木曜日の19:00〜21:00（50代ターゲットが最も視聴する時間帯）
4. 「スケジュール設定」または「公開」をクリック
5. 公開完了を秘書に報告

---

## YouTube Data API v3 を使ったアップロード（将来対応）

現状はYouTube Studioで手動アップロードを行う。
API自動化は以下のエンドポイントで実装可能：

| 処理 | エンドポイント |
|---|---|
| 動画アップロード | `POST /upload/youtube/v3/videos` (multipart) |
| プライバシー設定 | `status.privacyStatus: "private"` |
| サムネイル設定 | `POST /youtube/v3/thumbnails/set` |
| 公開切り替え | `PUT /youtube/v3/videos` で `status.privacyStatus: "public"` |

> API実装の優先度は社長判断。手動フローで運用が回っている段階では不要。

## アップロード後の連絡フロー

```
SNS_Manager（アップロード完了）
    ↓ 非公開URL + 確認メモ
秘書
    ↓ LINEまたはチケットで
社長（視聴・確認）
    ↓ GO / 修正指示
秘書
    ↓
SNS_Manager（公開処理 or Editor差し戻し）
```
