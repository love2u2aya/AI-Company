# SNS_Managerスキル：YouTube Analytics API 計測・レポート

## 目的

手動確認では拾えない「ロングテール動画が生きているか死んでいるか」を数字で判断する。
特に外部持込台本など、バズを狙わない動画の延命管理に使う。

---

## 使用するAPI

| API | 用途 |
|---|---|
| **YouTube Analytics API v2** | 再生数・CTR・視聴維持率・トラフィックソース |
| **YouTube Data API v3** | 動画メタデータ・コメント数・高評価数 |

> **認証**: OAuth 2.0（チャンネルオーナーの認証が必要）。APIキーはチャンネル管理者（社長）から取得し、ローカルには保存しない。

---

## 取得する指標と取得頻度

### 毎日取得（日次レポートに含める）

| 指標 | API パラメータ | 判断に使う目的 |
|---|---|---|
| 再生数 | `metrics=views` | 動画が発見されているか |
| インプレッション数 | `metrics=impressions` | アルゴリズムに押されているか |
| CTR | `metrics=impressionClickThroughRate` | タイトル・サムネが機能しているか（目標5%以上） |
| 視聴維持率（平均） | `metrics=averageViewPercentage` | 内容の質（目標40%以上） |

### 週次取得（週次レポートに含める）

| 指標 | API パラメータ | 判断に使う目的 |
|---|---|---|
| トラフィックソース別再生数 | `dimensions=insightTrafficSourceType` | 検索流入 vs アルゴリズム推薦の比率 |
| 検索キーワード流入 | `dimensions=insightTrafficSourceDetail` フィルタ: `insightTrafficSourceType==YT_SEARCH` | どの検索ワードで見られているか |
| 視聴者の年齢・性別 | `dimensions=ageGroup,gender` | ターゲット（50代女性）に届いているか |
| 登録者転換数 | `metrics=subscribersGained` | 動画が登録につながっているか |

### 月次取得（月次レポートに含める）

| 指標 | 判断に使う目的 |
|---|---|
| 収益（RPM・広告収入） | CPMが高い層（50代）に届いているか確認 |
| スプレッドシート集計値との差異確認 | 手動入力ミスがないかクロスチェック |

## ロングテール動画専用：生死判定フロー

ロングテール動画（バズ狙いでない動画）は以下の基準で毎月評価する。

```
月次チェック
    ↓
【判定A】検索流入が月100再生以上 → 生きている。何もしない
    ↓
【判定B】検索流入が月10〜100再生 → 要観察。固定コメントの更新検討
    ↓
【判定C】検索流入が月10再生未満、かつ3か月連続 → 死亡判定
         → 秘書に報告 → 非公開化 or タイトル・サムネ改修を提案
```

## トラフィックソースの読み方（ロングテール判断の核心）

YouTube Analytics のトラフィックソースは以下に分類される：

| ソース種別 | 意味 | ロングテールへの影響 |
|---|---|---|
| `YT_SEARCH` | YouTube内検索 | **最重要**。ここが生きていれば動画は延命できる |
| `SUGGESTED_VIDEO` | 関連動画経由 | アルゴリズム次第。バズ時は多いが安定しない |
| `EXTERNAL` | SNS・ブログ等の外部リンク | SNSで紹介された場合に増える |
| `BROWSE_FEATURES` | ホーム画面・急上昇 | バズ時のみ。ロングテールには関係薄い |
| `DIRECT` | URL直打ち・ブックマーク | リピーターまたはリンク流入 |

**ロングテール動画の理想的なトラフィック構成**：
- `YT_SEARCH` が全体の40%以上 → 安定した検索資産
- `YT_SEARCH` が全体の20%未満 → 検索に引っかかっていない。タイトル改修を検討

## 検索キーワード流入の分析（月次）

`insightTrafficSourceDetail` で「どの検索ワードで見られているか」が分かる。

### 確認手順（YouTube Studio でも代替可）

1. YouTube Studio → アナリティクス → トラフィックソース → 「YouTube 検索」を選択
2. 「詳細」タブで上位検索キーワードを確認
3. 以下を `AgentOutput/検索KWレポート_YYYYMM.md` に記録

```markdown
## 検索キーワードレポート｜YYYY年MM月

### 動画：[タイトル]

| 検索ワード | 流入再生数 | 順位変化 |
|---|---|---|
| 50代 新NISA 始め方 | 320 | 前月比+15% |
| オルカン 月5万 老後 | 180 | 前月比+3% |
| 新NISA 月3万 シミュレーション | 97 | 前月比-8% |

### 所見
- 「50代 新NISA 始め方」が主要流入ワード。検索順位を維持している
- 「月3万 シミュレーション」が微減。競合動画の投入を確認すること
```

## 固定コメント更新トリガーとの連動

`固定コメント運用_ロングテール延命.md` の更新判断をAPIデータで行う。

| データシグナル | 対応アクション |
|---|---|
| 検索流入が前月比-30%以上、かつ競合新動画が出た | 固定コメントに「最新情報」を追記してSEOを補強 |
| 「〇〇年 最新」など年号付き検索ワードからの流入増加 | 固定コメントに収録年の補足を追加 |
| 制度改正関連ワードからの流入増加 | 緊急対応レベル判定 → `固定コメント運用` ルールを参照 |

## YouTube Studio で代替する場合（API未接続時）

APIが使えない場合、YouTube Studio の以下の画面を順番に確認して同じ情報を取得する：

1. **アナリティクス → 概要タブ** → 再生数・視聴時間・登録者
2. **アナリティクス → リーチタブ** → インプレッション・CTR・トラフィックソース
3. **アナリティクス → エンゲージメントタブ** → 視聴維持率・最も再生された時間帯
4. **アナリティクス → 視聴者タブ** → 年齢・性別・リピーター率

> 手動確認の場合は取得に15〜20分かかる。週次・月次は手動可、日次は要自動化判断。
