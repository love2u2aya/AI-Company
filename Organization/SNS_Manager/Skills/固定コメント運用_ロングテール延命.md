# SNS_Managerスキル：固定コメント運用（ロングテール延命）

## 目的

金融系動画は制度改正・統計更新で陳腐化しやすい。
動画を撮り直さずに「固定コメント」の更新だけで延命する運用ルール。

---

## 対象動画

このルールを適用する動画には以下のタグをつけて管理する：
`#ロングテール運用対象`

現在の対象：
- 50代の新NISA｜月3万・5万・10万円シミュレーション（2026-05-11公開予定）

---

## 固定コメントの初期テンプレート（公開時に投稿）

```
📌【補足情報｜収録時点：2026年5月】

この動画内の数字は収録時点（2026年5月）の公的データを参照しています。
最新の数値は以下で確認できます。

【主なデータの参照先】
・NISA口座数・買付額 → 金融庁「NISA利用状況」
・物価上昇率 → 総務省「消費者物価指数」
・老後の生活費 → 総務省「家計調査」
・平均余命 → 厚生労働省「簡易生命表」

制度変更や大きな数値変化があった場合は、このコメントに追記します。
```

---

## 定期更新ルール（半年に1回）

**更新タイミング**: 毎年 6月・12月（各月の第1月曜日）

**更新手順**:

1. 以下の数値を各官公庁サイトで最新版に確認する

| 確認項目 | 確認先 | 動画内の表現 | 許容範囲 |
|---|---|---|---|
| NISA口座数 | 金融庁「NISA利用状況」 | 「年々伸びている」（丸め表現） | 増加傾向が続く限り変更不要 |
| 物価上昇率 | 総務省「CPI」 | 「年3%前後」 | 2〜4%の範囲内なら変更不要 |
| 老後生活費の不足額 | 総務省「家計調査」 | 「月4万円前後」（夫婦） | ±1万円以内なら変更不要 |
| 平均余命（50歳女性） | 厚生労働省「簡易生命表」 | 「約38年」 | ±1年以内なら変更不要 |

2. 「許容範囲」を超えた変更があった場合のみ、固定コメントに追記する

**追記フォーマット**:
```
【YYYY年MM月 追記】
○○が更新されました。
・旧：〇〇円 → 新：〇〇円（出典：総務省 家計調査 YYYY年版）
動画内の「〜〜」という説明は現在も概ね有効ですが、
最新の数値は上記に読み替えてご覧ください。
```

---

## 制度改正時の緊急対応ルール

**トリガー**：新NISAの制度変更・NISA枠の変更・税制改正

**対応レベル分類**:

| 変更の影響度 | 対応 | 担当 |
|---|---|---|
| 軽微（制度の枠組みは変わらない） | 固定コメントに追記のみ | SNS_Manager |
| 中程度（積立上限・対象商品に変更） | 固定コメント追記 + 社長に報告 | SNS_Manager → 秘書 |
| 重大（NISA制度そのものに変更） | 動画の非公開化検討 + 新規台本制作提案 | 秘書 → 社長判断 |

**緊急追記フォーマット**:
```
⚠️【重要：制度変更のお知らせ YYYY年MM月】
新NISAの○○が変更されました。
動画内の「〜〜」という説明は YYYY年MM月以降は適用されません。
最新のルールは金融庁の公式サイトをご確認ください。
この動画は変更前の情報として参考にしてください。
```
