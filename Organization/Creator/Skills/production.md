# Creatorスキル：動画制作

## 制作フロー

1. Plannerの企画書・構成案を確認
2. 必要な素材リストを作成
3. 撮影・収録（実写 or AI生成）
4. 素材をEditorに引き渡す（ファイル名・尺・内容を明記）
5. 成果物を `AgentOutput/素材_YYYYMMDD/` に格納

## チェックリスト（収録前）

- [ ] 企画の「落とし所」（オチ・結論）を理解しているか
- [ ] 冒頭15秒のつかみは明確か
- [ ] BGM・テロップで使う素材は準備できているか

## 成果物の置き場所

素材一覧メモ → `Workspace/Output/AgentOutput/素材一覧_YYYYMMDD.md`
