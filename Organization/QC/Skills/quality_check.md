# QCスキル：動画品質チェック・アップロード許可証発行

## 前提

QCはEditorから完成MP4を受け取ったあと、**公開前の最後の砦**として機能する。
「これは視聴者に出せるか」を映像・音声・数値・メタデータの4軸で確認する。

**QC PASSなしにSNS_Managerはアップロードを開始しない。**

---

## 受取物の確認

Editorから以下が揃っていることを確認してから作業開始する：

- [ ] 完成MP4（`FinalOutput/動画_YYYYMMDD_タイトル.mp4`）
- [ ] スライド指示書（Slide_Designerが作成。スクショ推奨スライドのTCと静止秒数が書かれたもの）
- [ ] 確定ナレーション原稿（Creatorが収録に使った最終版）
- [ ] メタデータ草案（タイトル・概要欄・タグ・チャプター）← SNS_Managerが準備

---

## チェックフロー

```
受取物の確認
    ↓
映像チェック（通し視聴1回目）
    ↓
音声チェック（通し視聴2回目・ヘッドフォン推奨）
    ↓
数値突合チェック（台本 vs スクリーン）
    ↓
メタデータチェック（概要欄・チャプター・タグ）
    ↓
PASS → QC報告書を発行 → SNS_Managerに連絡
FAIL → 差し戻しリストを作成 → Editorに送付
```

---

## 映像チェックリスト（通し視聴1回目）

動画を再生しながら以下を確認する。問題があった場合はタイムコードをメモする。

### 構成・テンポ

- [ ] 全体の尺が台本の想定尺（±1分以内）に収まっているか
- [ ] 冒頭3秒にインパクトワードのテロップが出ているか
- [ ] 各パートの冒頭に「ポイント①」等のテロップがあるか
- [ ] 「スクショしたくなるスライド」が最低2枚あるか
- [ ] エンドカード（関連動画2本＋登録ボタン）が末尾20秒に設定されているか

### スクショ推奨スライドの静止時間

Slide_Designerのスライド指示書と照合する：

| スライド | 指示書の要求 | 実際の静止時間 | 判定 |
|---|---|---|---|
| （指示書の記載を転記） | ○秒以上 | 実測値 | ○/× |

- [ ] 全スクショ推奨スライドが指示書の要求秒数を満たしているか

### 映像品質

- [ ] 黒フレーム・白飛びがないか
- [ ] スライドのアニメーションが途切れていないか
- [ ] テロップが画面の安全領域（上下左右80px）に収まっているか
- [ ] テロップに誤字・脱字がないか（画面上で目視確認）

---

## 音声チェックリスト（通し視聴2回目）

ヘッドフォンを使用して確認する。

- [ ] ナレーションとスライドのタイミングが合っているか（特に計算式スライドのアニメーション）
- [ ] ナレーションの音量が全編通して-12dB〜-6dB程度で安定しているか
- [ ] BGMがナレーションに被って聞き取れない区間がないか（BGMは-20dB以下が目安）
- [ ] 「えー」「あー」等の不要音が残っていないか
- [ ] 無音が2秒以上続く区間がないか（あれば編集ミスの可能性）
- [ ] 動画の冒頭と末尾の音声フェードが自然か

---

## 数値突合チェック（台本 vs スクリーン）

確定ナレーション原稿と、映像に表示される数字・テキストを1対1で照合する。

**特に確認すべき箇所**：

| 種別 | 確認内容 |
|---|---|
| 金額・数字 | 台本の数字とスライドに表示された数字が一致しているか |
| 計算式の結果 | 式の答えが正しいか（目視で計算） |
| 比較表 | 行・列の値が台本の記述と一致しているか |
| グラフ | 軸ラベル・値が正しいか |
| 出典表記 | スライドまたはテロップに出典が明記されているか |

**数値の不一致が1か所でもあれば即FAIL・差し戻し。**

---

## メタデータチェック

SNS_Managerが準備したメタデータ草案を以下で確認する：

- [ ] タイトルにメインキーワードが入っているか
- [ ] タイトルが長すぎないか（目安：40文字以内）
- [ ] 概要欄にチャプターが記載されているか（TC形式: `0:00 〇〇〇〇`）
- [ ] チャプターのTCが動画の実際の区切りと一致しているか
- [ ] 概要欄に参考資料リンクが含まれているか
- [ ] 概要欄に免責事項が含まれているか
- [ ] タグに主要キーワードが含まれているか（目安：10〜15個）
- [ ] サムネイル画像がアップロード予定であることをSNS_Managerに確認したか

## QC報告書フォーマット

保存先：`Workspace/Output/AgentOutput/QCレポート_YYYYMMDD_タイトル.md`

```markdown
# QCレポート｜YYYYMMDD｜[動画タイトル]

## 判定：PASS / FAIL

## チェック実施日時：YYYY-MM-DD HH:MM

## 結果サマリー

| チェック項目 | 判定 | 備考 |
|---|---|---|
| 映像・テンポ | ○/× | |
| スクショ静止時間 | ○/× | |
| 映像品質 | ○/× | |
| 音声品質 | ○/× | |
| 数値突合 | ○/× | |
| メタデータ | ○/× | |

## PASS の場合

SNS_Manager へ：アップロード許可を発行します。
非公開アップロードを開始してください。

添付：メタデータ確認済みチェックマーク

## FAIL の場合（差し戻し）

Editor へ：以下の修正をお願いします。

| TC | 問題内容 | 修正指示 |
|---|---|---|
| XX:XX | | |

修正後、再度QCに提出してください。
チケットをWaitingに移動します。
```

## アップロード後チェック（SNS_Managerのアップロード完了後）

SNS_Managerから「非公開アップロード完了・URL発行」の連絡を受けたら、
YouTubeの非公開URLで以下を最終確認する：

- [ ] チャプターが動画上で正しく機能しているか（YouTube側での表示確認）
- [ ] サムネイルが正しく設定されているか
- [ ] 概要欄のリンクが機能しているか（クリックして遷移確認）
- [ ] エンドカードの動画リンクが正しく設定されているか

確認完了後、秘書に「社長確認用URL」を渡す。
