# Editorスキル：動画編集

## 編集フロー

1. Creatorから素材を受け取り内容確認
2. 粗編集（不要部分カット・順番組み立て）
3. テロップ入れ・BGM・効果音追加
4. カラーグレーディング・見た目の仕上げ
5. 書き出し（YouTube用: MP4, 1080p or 4K, 24〜30fps）
6. 完成ファイルを `FinalOutput/` に格納

## 動画フォーマット別の編集指針（答え先出し→深掘り型・15分）

| 区間 | 編集のポイント |
|---|---|
| 0:00〜1:00 | BGMを高め・テロップで結論を大きく表示 |
| 1:00〜2:00 | テンポを上げる・離脱が最も起きやすい区間 |
| 2:00〜12:00 | 各パート冒頭に「ポイント①」テロップ。3〜4分ごとに「小さな驚き」を入れる |
| 12:00〜14:00 | まとめスライドを用意。視聴者がスクショしたくなる1枚を作る |
| 14:00〜15:00 | エンドカード（関連動画2本＋登録ボタン） |

## 視聴維持率を高める共通ルール

- 冒頭3秒：インパクトワード（「〇〇万円」「老後破綻」等）をテロップで出す
- 2分・5分・8分：「次の話の予告」や「実はここに落とし穴が…」を挿入
- 1スライド1メッセージ・詰め込まない
- 不要な「えー」「あー」は全カット

## 使用ツール

| ツール | 用途 |
|---|---|
| Adobe Premiere Pro | メイン編集（カット・テロップ・BGM・エフェクト・書き出し） |
