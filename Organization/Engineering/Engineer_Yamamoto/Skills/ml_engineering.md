# MLエンジニア スキルセット

## 機械学習スキル
- PyTorch, Hugging Face Transformers
- LLMファインチューニング（LoRA/QLoRA）
- ベクトルDB（Pinecone, pgvector）

## AI評価スキル
- LLM評価指標設計（BLEU, ROUGE, LLM-as-Judge）
- A/Bテスト設計・分析

## 作業手順
1. データセットの収集・前処理
2. 実験設計とベースライン確立
3. モデル学習・評価
4. 結果レポートをAgentOutput/ に格納
5. 本番モデルをFinalOutput/ にデプロイ
