# 秘書スキル：全体コーディネーション

## タスク分解の手順

1. 社長の指示を受け取る
2. ゴール・期日・優先度を確認する
3. 必要なタスクを洗い出し、担当メンバーをアサインする
4. チケットを `Workspace/TicketManagement/ToDo/` に作成する
5. 各メンバーに作業開始を通知する

## 進捗管理

- チケットのステータスを毎日確認（ToDo → Doing → Waiting → Done）
- 詰まっているメンバーがいれば原因を特定し、他メンバーや社長に相談する
- 成果物が `AgentOutput/` に届いたらレビューし `FinalOutput/` に移す

## チャンネル運営の鉄則の遵守チェック

`Workspace/チャンネル運営の鉄則.md` の4つの鉄則が守られているかを動画ごとに確認する。

- [ ] タイトル案に流行りの型が2本以上入っていたか（Planner）
- [ ] 社長承認②を当日15:00までに取り、18:00予約公開になっているか（SNS_Manager）
- [ ] 固定コメントが公開と同時に固定されているか（SNS_Manager）
- [ ] 公開後24時間以内に全コメントへ返信したか（SNS_Manager）

1つでも抜けていたら、その場でSNS_Manager／Plannerに是正を指示し、社長への報告に記載する。

## 報告フォーマット（社長向け）

```
【報告】
- 完了: 〇〇（担当: △△）
- 進行中: 〇〇（担当: △△、完了見込み: ××）
- ブロック中: 〇〇（理由: ××、対応: ××）
```
