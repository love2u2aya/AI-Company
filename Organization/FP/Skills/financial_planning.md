# FPスキル：深層洞察・コンテンツ監修

## FPが動くタイミング（3つ）

| タイミング | インプット | アウトプット |
|---|---|---|
| **企画前** | テーマ候補・トレンド情報 | 深掘りブリーフ（企画の核心となる洞察） |
| **企画後** | Plannerの企画書 | 監修コメント（深さ・正確性・抜け漏れ） |
| **台本後** | Creatorのナレーション原稿 | ファクトチェック＋言い回し修正案 |

---

## 1. 深掘りブリーフの作り方

Plannerがテーマを決める前に、FPが「そのテーマで語れる最も深い話」を整理して提供する。

### ブリーフに含める項目

```
【テーマ】

【一般人が知っている表層の話】
→ 視聴者がすでに「なんとなく知っている」レベル。これだけでは差別化できない。

【その一段深い話】
→ 少し調べると出てくるが、整理されていない情報。ここまでが多くのYouTubeの水準。

【FPだけが知っている深層の話】
→ 実務経験・相談事例・税務・行動経済学から導かれる洞察。
→ 「へー、そんな落とし穴があるのか」と視聴者が感じるレベル。

【視聴者の典型的な誤解・失敗パターン】
→ 実際の相談で何度も見てきた「やりがちなミス」

【家族構成・ライフフェーズ別の違い】
→ 独身 / 共働き / 片働き / 子あり / 子なし / 親の介護あり などで判断が変わる点

【今この時期に語る意味（タイムリー性）】
→ 制度改正・税制・社会変化との接続

【コンテンツで言うべきでないこと（リスク管理）】
→ 誤解を招く表現・断定的すぎる言い回し・特定商品への誘導に見える表現
```

## 2. 監修コメントのフォーマット

企画書・台本を受け取ったら、以下の形式でコメントを返す。

```markdown
# FP監修コメント｜YYYY-MM-DD

## 対象ファイル
`AgentOutput/企画_YYYYMMDD.md` または `AgentOutput/ナレーション原稿_YYYYMMDD.md`

## 総評
（全体的な深さ・正確性の評価を2〜3文で）

## 良い点
- （具体的に）

## 修正・強化が必要な点

| 箇所 | 現状の表現 | 問題点 | 修正案 |
|---|---|---|---|
| ○ページ目 | 「〜です」 | 〜という誤解を招く | 「〜ただし〜の場合は例外」 |

## 追加すべき洞察
（このテーマで語れるのに語られていない「深い話」）

## 法的・倫理的注意事項
（断定表現・特定商品推奨・誤解リスクがある箇所の指摘）
```

## 3. FPが持つ「深層の引き出し」（テーマ別）

### 老後・退職金

- 退職金の受け取り方（一括 vs 年金型）で税額が数百万変わる
- 退職所得控除の2024年改正と長期勤続者への影響
- 「退職金特別プラン」の手数料は3年後に消える仕組み
- 早期退職・希望退職の退職金は通常退職と課税が異なる
- 退職後すぐに資産運用を始めてはいけない「感情の問題」

### 年金

- 繰り下げ受給の損益分岐点は「何歳まで生きるか」だけで決まらない
- 在職老齢年金の「壁」を超えると手取りが逆転する逆説
- 加給年金・振替加算を知らない夫婦が毎年損している金額
- iDeCo受け取り時の「退職所得枠の奪い合い」問題
- 年金の繰り下げ中に死亡した場合の「死に損」を防ぐ方法

### 投資・資産運用

- 新NISAの「成長投資枠」を50代が使うべき商品は積立と全く違う
- 50代からのポートフォリオは「増やす」より「減らさない」設計
- 債券・REITを混ぜる理由は利回りではなく「時間軸の分散」
- 出口戦略なき積み立ては「貯めるだけ」で終わるリスク
- 暴落時に売ってしまう人の心理と、それを防ぐ設計の仕方

### 家族・ライフプランニング

- 「老後資金2,000万円」は単身 or 夫婦か、持ち家 or 賃貸かで全く変わる
- 子どもの教育費ピークと老後資金形成期が重なる「ダブルピーク世代」の戦略
- 親の介護費用を「見て見ぬふり」すると自分の老後資金が消える
- 離婚した場合の年金分割制度と、知らないと損する申請タイミング
- 相続は「もらう側」より「渡す側」が早めに動かないと税金が増える

### 行動経済学・心理

- 「損失回避バイアス」が投資の失敗を生む仕組み
- 退職金を受け取った直後が最も判断力が下がる心理的理由
- 「なんとかなる」思考が老後破綻を引き起こすメカニズム
- お金の話を家族でできない日本人特有の問題と解決策

## 4. コンテンツに入れてはいけない表現（リスク管理）

| NG表現 | 理由 | 代替表現 |
|---|---|---|
| 「〇〇に投資すれば必ず儲かる」 | 断定的な投資推奨は金融商品取引法違反リスク | 「〜という可能性があります」 |
| 「銀行は絶対ダメ」 | 属性・状況によっては銀行預金が最適な場合もある | 「〜の方には向かない可能性があります」 |
| 「今すぐ〇〇しないと損」 | 煽りすぎ・誤った緊急性の演出 | 「早めに確認しておくことをおすすめします」 |
| 特定の証券会社・保険商品名の言及 | 特定推奨・広告規制のリスク | 商品カテゴリで説明する |
