# Slide Designerスキル：動画内スライド制作フロー

## 前提

この動画は「顔出しなし・スライド画面＋肉声ナレーション」形式。
スライドが映像の100%であり、スライドの品質 = 動画の品質である。

**絶対的基準**: 「これ、プロが作ったのか？」と視聴者に感じさせること。
文字を並べただけの資料は作らない。数字・図解・アイコンで語る。

---

## 制作フロー

```
Creator ナレーション原稿（確定版）
    ↓
Slide Designer が全スライドを設計（スライドマップ作成）
    ↓
デザインシステムに沿って各スライドを制作
    ↓
PowerPoint でアニメーション設定
    ↓
MP4書き出し（または静止画+指示書）
    ↓
Editor へ引き渡し（テロップ・BGM・SE の追加は Editor が行う）
```

## デザインシステム（パパママ社 標準）

### カラーパレット

| 用途 | カラー | HEX | 使用場面 |
|---|---|---|---|
| 背景 | ダークネイビー | `#0A1628` | 全スライド共通 |
| 強調数字・見出し | ゴールド | `#FFD700` | キーナンバー・セクション見出し |
| 警告・減少・NG | クリムゾン | `#CC2200` | 損失額・やってはいけないこと |
| 中立情報・ステップ番号 | スカイブルー | `#4A9FD4` | 手順番号・補足情報 |
| 本文テキスト | ホワイト | `#FFFFFF` | 主要テキスト |
| 副テキスト | ライトグレー | `#CCCCCC` | 注記・出典 |

> **ルール**: 1スライドで使う色は最大3色（背景含む）。色が多いスライドは設計を見直す。

### タイポグラフィシステム

| レベル | フォント | サイズ（1920×1080基準） | 用途 |
|---|---|---|---|
| インパクト数字 | Noto Sans JP Black | 96〜140px | 1スライドで1つだけ出す核心数字 |
| セクション見出し | Noto Sans JP Bold | 60〜72px | 補正①・まとめ等のゾーン見出し |
| 本文 | Noto Sans JP Regular | 36〜44px | 説明文・リスト項目 |
| キャプション | Noto Sans JP Light | 26〜32px | 出典・注記・補足 |

> **ルール**: 1スライド内で使うサイズは最大3種類。フォントはNoto Sans JP統一。

### グリッドシステム

- キャンバスサイズ: 1920 × 1080px
- 安全領域マージン: 上下左右 80px（テレビ・スマホで切れないエリア）
- コンテンツ幅: 最大 1760px
- 中央揃えを基本とする。左寄せは3列以上のリストのみ

## スライドタイプ別テンプレート

### Type 1: インパクト数字スライド
**用途**: 冒頭の衝撃数字・各パートの核心数字を1枚で伝える

```
┌─────────────────────────────────┐
│  [上部：小さなコンテキスト文字]       │  ← 白 36px
│                                 │
│     【核心数字】                   │  ← ゴールド 120px ± Noto Black
│                                 │
│  [下部：1行の補足説明]              │  ← ライトグレー 32px
└─────────────────────────────────┘
```

**使用例**: 「月22万円」「約960万円のズレ」「20年間」

**NG例**: 数字と説明文を両方大きくする → インパクトが分散する

---

### Type 2: ビフォーアフター（修正対比）スライド
**用途**: 誤解と正解・修正前と修正後の対比

```
┌────────────────┬────────────────┐
│   【ビフォー】    │   【アフター】    │
│                │                │
│  ~~月22万円~~   │    月18万円     │
│  取り消し線+深紅  │  ゴールド強調    │
│                │                │
│   ←誤解・NG     │   ←正解・OK    │
└────────────────┴────────────────┘
```

**使用例**: 定期便の額面 vs 手取り、「×30年計算」vs 前後半分割

---

### Type 3: 計算式スライド（アニメーション必須）
**用途**: 計算プロセスを視覚的に段階的に見せる

```
アニメーション順序:
① 計算要素A が表示         「月22万円」（白）
   ↓（0.5秒後）
② 演算子が表示             「×」（スカイブルー）
   ↓（0.5秒後）
③ 計算要素B が表示         「0.87」（ゴールド）
   ↓（0.5秒後）
④ 「＝」が表示             「＝」（白）
   ↓（0.5秒後）
⑤ 結果が大きく表示（フェードイン+スケールアップ）
                          「約19万円」（ゴールド 120px）
```

**レイアウト**: 横並び（A × B ＝ C）または縦積み（縦に長い式）
**PowerPointアニメーション**: 要素ごとにフェードイン、間隔0.3〜0.5秒

---

### Type 4: ステップ進行スライド
**用途**: 3補正・3ステップ等の手順を示す。各パートで「今ここ」を強調

```
┌─────────────────────────────────┐
│  補正① ← 【今ここ】 ゴールド強調    │
│  ─────────────────────────────  │
│  補正② ← 薄いグレーアウト         │
│  ─────────────────────────────  │
│  補正③ ← 薄いグレーアウト         │
└─────────────────────────────────┘
```

各パートの冒頭スライドに使用。進行に合わせてアクティブなステップを変える。

---

### Type 5: 比較表スライド（スクショ推奨）
**用途**: 複数シナリオの一覧・やってはいけないこと等

```
┌──────────────┬──────────────────┬──────────────────┐
│ シナリオ名    │ 内容説明          │ 金額              │
├──────────────┼──────────────────┼──────────────────┤
│ 入院なし      │ 通院・薬代中心    │ 300〜500万円      │ ← 青行
├──────────────┼──────────────────┼──────────────────┤  
│ 短期入院 ★   │ 手術2〜3回       │ 600〜900万円      │ ← 白行 + ★強調
├──────────────┼──────────────────┼──────────────────┤
│ 長期療養      │ 長期入院・先進医療│ 1,000〜2,000万円  │ ← 赤行
└──────────────┴──────────────────┴──────────────────┘
「📸 スクショしてください」（右上に配置）
```

**スクショ用スライド必須条件**:
- 全要素が揃ってから最低10秒静止させる（Editorへ指示書で伝える）
- 白枠線（2px）で囲む
- 「スクショしてください」アイコンを右上に配置

---

### Type 6: インフォグラフィック（図解）スライド
**用途**: 抽象的な概念・仕組みを視覚化する

**例: 「老後の収入 vs 支出」の図解**
```
収入ライン ─────── ←年金手取り（ゴールド矢印）
               ↘
               ギャップゾーン（赤ハッチング）
支出ライン ─────── ←生活費（白矢印）
```

**アイコン活用ルール**:
- テキストで書けるものをアイコンに置き換える
- 「円マーク」「家」「医療」「老人」「時計」など定番アイコンを統一使用
- アイコンのスタイルは1動画内で統一（フラット or ラインアート）

---

### Type 7: グラフスライド
**用途**: 数値の推移・割合・比較を客観的に示す

**棒グラフのルール**:
- 背景はダークネイビー
- 棒の色: 比較軸に応じてゴールドvsクリムゾン
- 軸ラベル: 白 32px
- 数値ラベルを棒の上に表示
- PowerPointのアニメーション: 棒が下から伸びる（Wipe Up）

**円グラフのルール**:
- セクション数は最大4つ（それ以上は「その他」に統合）
- 注目すべきセクションをゴールドかクリムゾンで強調

## アニメーション設計（PowerPoint）

### 基本原則
- **1スライド1アニメーション原則**: 1枚のスライドで動く要素は最大3つまで
- **テンポ**: フェードイン 0.3秒。要素間の間隔 0.4〜0.7秒
- **ナレーションと同期**: アニメーション登場タイミングはナレーション原稿のセリフと必ず対応させる

### アニメーション種別ルール

| 演出目的 | アニメーション種類 | 設定 |
|---|---|---|
| 要素の登場 | フェード | 0.3秒 |
| 数字の強調 | スケールアップ（100%→115%→100%） | 0.4秒 |
| 警告・驚き | パルス（点滅1回） | 0.3秒 |
| ステップ進行 | ワイプ（左から） | 0.4秒 |
| グラフ伸長 | ワイプ（下から） | 0.7秒 |
| スライド退場 | フェードアウト | 0.2秒 |

> **NG**: フライイン（派手な飛び込み）・スピン・バウンスは使わない。コンテンツに集中させる。

### 計算式スライドのアニメーション必須手順
1. 要素A（フェードイン 0.3秒）
2. 間0.5秒
3. 演算子（フェードイン 0.3秒）
4. 間0.5秒
5. 要素B（フェードイン 0.3秒）
6. 間0.5秒
7. 「＝」（フェードイン 0.3秒）
8. 間0.7秒
9. 結果（フェードイン＋スケールアップ 0.5秒）← 最もゆっくり・大きく

## スライドマップの作成（制作前の必須工程）

ナレーション原稿を受け取ったら、制作を始める前に必ず**スライドマップ**を作成する。

### スライドマップのフォーマット

```markdown
# スライドマップ｜YYYY-MM-DD｜タイトル

| No. | TC（目安） | ナレーションの該当部分 | スライドタイプ | 核心要素 | アニメーション |
|---|---|---|---|---|---|
| 1 | 0:00〜0:05 | 「月22万円が…」 | Type1 インパクト数字 | 「月22万円」ゴールド140px | なし |
| 2 | 0:05〜0:10 | 「口座に入るのは…」 | Type2 ビフォーアフター | 22万→18万 | フェードイン |
...
```

このマップをEditorと共有し、テロップのタイミングと整合させる。

## 品質チェックリスト（納品前）

### デザイン品質
- [ ] 1スライド1メッセージになっているか（詰め込んでいないか）
- [ ] カラーパレット（4色 + 白・グレー）から逸脱していないか
- [ ] フォントはNoto Sans JP の4レベル体系に収まっているか
- [ ] インパクト数字スライドで「数字以外の要素が主張していないか」
- [ ] 比較表・グラフのカラーコーディングが一貫しているか
- [ ] 「スクショしたくなる」スライドが2枚以上あるか

### アニメーション品質
- [ ] 各スライドのアニメーションは最大3要素か
- [ ] フェードインのデフォルト時間は0.3秒か
- [ ] 計算式スライドは要素が順次登場しているか（一気に表示していないか）
- [ ] NG演出（フライイン・スピン・バウンス）を使っていないか
- [ ] ナレーション原稿のセリフと要素の登場が対応しているか

### データ・数字の正確性
- [ ] FP台本チェック通過済みの確定原稿を使っているか
- [ ] グラフ・表の数字は原稿と一致しているか
- [ ] 計算式の計算結果が正しいか（自分で検算する）

### 書き出し設定
- [ ] MP4 / 1920×1080 / 30fps
- [ ] 静止スライド（アニメーションなし）は 5秒以上の尺を確保
- [ ] 「スクショ推奨スライド」は 12秒以上の尺を確保

## Editorへの引き渡し

成果物と一緒に「スライド指示書」を作成して渡す：

```markdown
# スライド指示書｜YYYY-MM-DD

## 構成
- スライド総枚数: XX枚
- 動画想定尺: 約15分

## スクショ推奨スライド
- No.XX「医療費3シナリオ比較表」（TC: 約11:00）→ 12秒以上静止してください
- No.XX「やってはいけないこと3点」（TC: 約13:45）→ 10秒以上静止してください

## 特記事項
- No.5 計算式スライド: 要素が5段階でアニメーションする。ナレーション「定期便の見込み額×0.87=」に合わせてください
- No.12: BGMを一瞬落としてほしい（驚きの演出）
```

## NGデザイン例（これを絶対にやらない）

| NG | 理由 | 代替案 |
|---|---|---|
| 白背景に黒文字 | ライブ配信感・安っぽく見える | ダークネイビー背景を使う |
| 箇条書き5行以上 | 読む気が失せる・情報過多 | 最大4行。それ以上はスライドを分割 |
| 全て同じサイズのテキスト | 何が重要か伝わらない | インパクト数字と説明文で3段階以上の差をつける |
| グラデーション多用 | ゴチャついた印象 | 単色フラット＋アクセントカラー |
| フォントを複数種類使う | ブランド感がなくなる | Noto Sans JP 1種のみ、ウェイトで差をつける |
| テキストを画像の上に重ねる | 可読性が下がる | 半透明の黒帯を敷いてからテキストを置く |
| アニメーションなし（静止のみ） | 退屈・視聴維持率が下がる | 計算式は必ずアニメーション。最低限フェードイン |
