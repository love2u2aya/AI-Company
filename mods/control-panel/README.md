# control-panel（コントロールパネル mod）

Claude Code の作業状況を別ペインにまとめて表示する mod。
社長が「いま秘書（Claude）が何をしていて、どこまで進んだか」を一目で確認するためのもの。

## 表示内容

| タブ | ホットキー | 内容 |
|---|---|---|
| 概要 | `1` | 下の4つを1画面に要約。残りトークンのバーも出る |
| サブエージェント | `2` | 起動したサブエージェントの一覧（説明・種類・状態） |
| 進捗 | `3` | TodoWrite / TaskCreate / TaskUpdate のタスクと完了率 |
| 履歴 | `4` | 指示・ツール実行・サブエージェントの起動/完了・ターン完了の時系列ログ（最新500件） |

- **トークン**: コンテキストウィンドウの使用量と残り、コスト、レート制限（取得できる場合）
- **現在の作業**: 作業中か待機中か、何回目の指示か、開始時刻、ツール呼び出し回数
- サブエージェントの状態とトークン量は3秒ごとに更新される

## 使い方

- セッション開始時にペインが自動で開く
- 閉じた後は `/panel` で開き直せる
- ペインにフォーカスがある間は `1`〜`4` でタブを切り替えられる

## インストール

ターミナルの Claude Code のプロンプトで次を入力する：

```
/plugin install control-panel --marketplace love2u2aya/AI-Company
```

マーケットプレイスを追加するか聞かれたら `y` を押し、スコープを選ぶ（通常はユーザースコープ）。

## 開発

```
claude plugin validate mods/control-panel
claude plugin test mods/control-panel
```

| ファイル | 役割 |
|---|---|
| `hooks/register.tsx` | フック本体（イベント収集とペインの描画） |
| `types/index.d.ts` | `$.state` に保存する値の型 |
| `tests/panel.test.tsx` | 進捗の表示とタブ切り替えのテスト |
