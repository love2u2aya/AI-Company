# choice-buttons（選択肢ボタン mod）

秘書（Claude）が社長に「どうしますか？」と選択を求めたとき、プロンプトの上にボタンを出す mod。
社長は文字を打たずに、ボタンを押すだけで答えられる。

```
押して答える（入力欄が空なら数字キーでも押せます）
[ 1 はい ] [ 2 いいえ ] [ 閉じる ]
```

## ボタンが出るとき

Claude の返答が終わったとき、その最後の部分を見て判断する。

| 返答の終わり方 | 出るボタン |
|---|---|
| `選択肢: A案 / B案 / もう少し考える` の行 | `1 A案` `2 B案` `3 もう少し考える` |
| 質問のあとに番号付きリスト（`1.` `2)` `①` など） | `1 1. …` `2 2. …` のように番号ごと |
| 「〜してよいですか？」のような、はい／いいえで答えられる質問 | `1 はい` `2 いいえ` |

- 「何にしますか？」「どれがいい？」のように、はい／いいえで答えられない質問ではボタンは出ない
- Claude には、選択を求めるときは最後の行に `選択肢: …` を書くようシステムプロンプトで伝えてある
- ボタンは最大9個。押した選択肢の文字が、そのまま社長の返答として送られる

## 使い方

- ボタンをクリックする（入力欄が空なら数字キー `1`〜`9` でも押せる）
- 自分で文字を打って送った場合や、`閉じる` を押した場合は、ボタンは消える
- Claude が作業している間はボタンは出ない

ボタンの帯はターミナルとデスクトップアプリで表示される（モバイルアプリには表示されない）。

## インストール

ターミナルの Claude Code のプロンプトで次を入力する：

```
/plugin install choice-buttons --marketplace love2u2aya/AI-Company
```

マーケットプレイスを追加するか聞かれたら `y` を押し、スコープを選ぶ（通常はユーザースコープ）。

## 開発

```
claude plugin validate mods/choice-buttons
claude plugin test mods/choice-buttons
```

| ファイル | 役割 |
|---|---|
| `hooks/register.tsx` | フック本体（返答から選択肢を読み取り、ボタンを描画する） |
| `types/index.d.ts` | `$.state` に保存する値の型 |
| `tests/buttons.test.tsx` | 選択肢の読み取り・ボタンを押したときの送信・消えるタイミングのテスト |
