# チャンネルコンセプト

## 基本情報

| 項目 | 内容 |
|---|---|
| ジャンル | 投資・老後資産・年金 |
| ターゲット | 50〜60代・老後直前世代 |
| 視聴者の悩み | 「年金だけで足りるのか」「今から投資は遅いか」「資産をどう守るか」 |
| チャンネルの立ち位置 | 難しい話をわかりやすく・不安を解消して行動を促す |
| 制作スタイル | 顔出しなし・スライド＋肉声ナレーション |

---

## ターゲット視聴者の解像度

**メインペルソナ：55歳・会社員**
- 老後まであと5〜10年
- 退職金があることはわかっているが、それだけで足りるか不安
- NISAやiDeCoの名前は聞いたことがあるが、よくわからない
- 投資は「怖い・難しい・騙されそう」というイメージがある
- 難しい専門用語が多い動画は途中で離脱する

---

## バズる企画の方向性

### ◎ 刺さりやすいテーマ
- 「年金〇万円では足りない」系の危機感訴求
- 「退職金の正しい使い方」「やってはいけない運用」
- 「60歳からでも遅くない〇〇」という希望提示
- NISAや新制度の「要点だけ3分で解説」
- 「実際いくら必要か」シミュレーション系

### × 避けるべきテーマ
- 短期・高リターンを煽る投機的な内容
- 専門用語を多用した難解な解説
- 若者向けの積立NISAのみに特化した内容

---

## コンテンツの型

| 型 | 例 |
|---|---|
| 危機感→解決策 | 「年金月15万では老後破綻する理由と対策」 |
| ランキング | 「60代がやってはいけない資産運用ワースト3」 |
| シミュレーション | 「退職金2000万をどう運用すべきか試算してみた」 |
| ニュース解説 | 「話題の〇〇制度、50代が知るべきポイントだけ解説」 |
| 初心者向け入門 | 「NISAを今から始める55歳のリアルなやり方」 |
