# パパママ社 ツール一覧

## メンバー別ツール

| メンバー | ツール | 用途 |
|---|---|---|
| Planner | YouTube Studio | 競合・トレンド分析 |
| Planner | Google トレンド | 検索トレンド調査 |
| Planner | ChatGPT / Claude | 企画出し・タイトル生成 |
| Planner | 各種API | データ収集・自動調査 |
| Planner | Notion / スプレッドシート | 企画書・ネタ管理 |
| Creator | PowerPoint / Google スライド | 動画の画面素材制作 |
| Creator | マイク（肉声） | ナレーション録音 |
| Editor | Adobe Premiere Pro | 動画編集・書き出し |
| Designer | ChatGPT（GPT-image-2） | サムネイル画像AI生成 |
| SNS_Manager | YouTube Studio | 投稿・収益・アナリティクス |
| 全員 | LINE | 社長への報告・確認 |

## 制作スタイルのルール

- **顔出しなし**: 動画の画面はスライド資料のみ
- **ナレーション**: 肉声録音（AIボイス不使用）
- **サムネイル**: ChatGPT GPT-image-2でAI生成
- **社長報告**: LINEで行う（ファイルはWorkspace/Output/に置く）
