# 業務フロー：動画1本の制作サイクル

**制作期間**: 3日  
**投稿頻度**: 週3〜5本（複数本が並行進行）  
**社長承認**: 企画後・完成後の2回

---

## 全体の流れ

```
Day 1【企画】       Day 2【制作】          Day 3【仕上げ・公開】
Planner 企画        Creator 撮影/素材       Editor 編集完了
    ↓               Designer サムネイル案        ↓
  秘書 → 社長承認①     ↓ (並行)           秘書 → 社長承認②
    ↓               Editor 編集開始              ↓
  GO!                                      SNS_Manager 投稿
```

---

## Day 1：企画フェーズ

### Planner のタスク
1. トレンドワードをリサーチ（YouTube / TikTok / X）
2. 企画案を3〜5本出す
3. 各案に以下を添付して企画書を作成：
   - タイトル案（3パターン）
   - 構成概要（冒頭つかみ30秒・本編・オチ）
   - ターゲット視聴者
   - サムネイルコンセプト案
4. `Workspace/Output/AgentOutput/企画_YYYYMMDD.md` に保存
5. 秘書に提出

### 秘書のタスク
- 企画書を受け取り、**社長に提出**
- 社長のGO/NG判断を待つ

### ✅ 社長承認①（企画承認）
> **社長が確認すること**
> - どの企画案でいくか選ぶ（または修正指示）
> - バズりそうか・会社の方向性と合っているか

- **GO** → 秘書が制作フェーズを開始
- **NG** → Planner に差し戻し・再企画

### 承認後：秘書のタスク
- チケットを `TicketManagement/Doing/` に作成
- Creator / Designer / Editor に制作指示を出す

---

## Day 2：制作フェーズ（並行作業）

### Creator のタスク
1. 企画書の構成に沿って撮影・収録
2. 素材を整理し、Editorに引き渡す
3. `AgentOutput/素材一覧_YYYYMMDD.md` に素材リストを保存

### Designer のタスク
1. 企画書のサムネイルコンセプトをもとに2〜3案制作
2. `AgentOutput/サムネイル案_YYYYMMDD/` に保存
3. 秘書に提出（社長が後で選ぶ）

### Editor のタスク
1. Creatorから素材が届き次第、編集開始
2. カット → テロップ → BGM → エフェクト → カラー
3. Day 3午前中に完成を目指す

---

## Day 3：仕上げ・公開フェーズ

### Editor のタスク
1. 編集を完了し書き出す
2. `FinalOutput/動画_YYYYMMDD_タイトル.md` に完成情報を記録
3. 秘書に完成報告

### 秘書のタスク
- Editor からの完成報告を受け取る
- Designer のサムネイル案と合わせて**社長に提出**

### ✅ 社長承認②（公開承認）
> **社長が確認すること**
> - 動画の内容・クオリティに問題がないか
> - サムネイルをどれにするか選ぶ
> - 公開タイミングの確認

- **GO** → SNS_Manager に公開指示
- **修正** → 該当メンバーに差し戻し（チケットを `Waiting/` に移動）

### SNS_Manager のタスク
1. 採用サムネイルを `FinalOutput/` に確定保存
2. 各プラットフォームの説明文・ハッシュタグ・タグを作成
3. 最適な時間帯に投稿スケジュール設定
4. 投稿完了を秘書に報告

### 秘書のタスク
- チケットを `TicketManagement/Done/` に移動
- 社長に完了報告（報告フォーマットを使用）

---

## 並行進行のイメージ（週3〜5本体制）

```
月        火        水        木        金
企画A     制作A     公開A
          企画B     制作B     公開B
                    企画C     制作C     公開C
                              企画D     制作D
```

Planner は毎日企画を出し続け、CreatorとEditorは常に制作中の状態を維持する。

---

## チケットの動き（1本の動画の場合）

```
ToDo → Doing（Day1承認後）→ Waiting（Day3差し戻し時のみ）→ Done（投稿完了）
```
