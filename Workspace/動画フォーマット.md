# 動画フォーマット（標準テンプレート）

**尺**: 15分前後  
**型**: 答え先出し→深掘り型  
**スタイル**: 顔出しなし・スライド画面＋肉声ナレーション

---

## 構成テンプレート

### 0:00〜1:00 ｜ 結論＋予告（つかみ）
- 結論を最初に言い切る
  > 「結論から言います。〇〇は△△すべきです」
- 理由の数を宣言して期待値を作る
  > 「その理由を3つ、順番に説明します」
- **編集ポイント**: BGMを少し高めに・テロップで結論を大きく表示

### 1:00〜2:00 ｜ なぜ重要か（危機感・期待値）
- 「知らないとどうなるか」を具体的に伝える
  > 「この話を知らないと、老後に〇〇万円損する可能性があります」
- 視聴者が「最後まで見る理由」を作る
- **編集ポイント**: ここで離脱が起きやすい。テンポを上げる

### 2:00〜12:00 ｜ 理由①②③の深掘り（本編）
各パート約3〜4分。以下のリズムで繰り返す：

```
ポイント提示（30秒）
　↓
具体的な数字・事例で説明（2〜3分）
　↓
「小さな驚き」で離脱を防ぐ（30秒）
　例：「実はここに落とし穴があります」
　　　「多くの人が勘違いしているのですが…」
```

- **編集ポイント**: 各パートの冒頭にテロップで「ポイント①」と明示。中だるみを防ぐ

### 12:00〜14:00 ｜ まとめ＋よくある失敗
- 3つのポイントを30秒で復習
- 「やってはいけないこと」で締める
  > 「最後に、やってはいけないことを1つお伝えします」
- **編集ポイント**: まとめスライドを用意。視聴者がスクショしたくなる設計に

### 14:00〜15:00 ｜ 次回予告＋CTA
- 次の動画への橋渡し（シリーズ化を意識）
  > 「次回は〇〇について解説します」
- チャンネル登録・高評価の呼びかけ
- **編集ポイント**: エンドカードを表示（関連動画2本＋チャンネル登録ボタン）

## 視聴維持率を高めるルール

| タイミング | やること |
|---|---|
| 冒頭3秒 | 「〇〇万円」「老後破綻」などインパクトワードをテロップで出す |
| 2分・5分・8分 | 「小さな驚き」や「次の話の予告」を入れて離脱を防ぐ |
| 全体を通して | 1スライドに情報を詰めすぎない。1枚1メッセージ |
| ナレーション | 1文を短く。結論→理由の順で話す |

## Plannerへの企画書必須記載事項

```
【タイトル案】（必ず3パターン）← YouTubeのタイトルA/Bテスト機能で3つ同時出稿し視聴率で比較する
【結論（0:00に言う一言）】
【理由①②③の見出し】
【小さな驚きのネタ（各パートに1つ）】
【やってはいけないこと（締め用）】
【次回への橋渡しネタ】
```

## A/Bテスト方針

| 対象 | 方針 |
|---|---|
| タイトル | **3案必須。YouTubeのタイトルA/Bテスト機能を使い、視聴率で自動比較する** |
| サムネイル | **A/Bテスト機能は使わない。1案に絞って投稿する** |

| 4 | 顕在ニーズ→潜在ニーズへの裏返し | 「皆さんが知りたいのは◯◯ですよね。でも本当に大事なのは△△」 |

| 10 | CTAは具体的ギフト付き | 「シミュレーターをプレゼント」「個別相談」などLINE誘導の餌を明示 |

### 演出指示の必須3要素（台本に書き込むこと）

1. **BGMの感情曲線**: 冒頭（緊張）→ 本編（軽快・知的）→ 転換点（温かい）→ マインド編（壮大）→ CTA（静かなピアノ）
2. **カメラワーク／表情指示**: 「真っ直ぐ見て、少し厳しめの表情から」「優しい笑顔に切り替えて」「アップへ」など、Editor/Creatorが画作りできる粒度で
3. **スクショされる「まとめスライド」**: 動画後半で3点まとめを1枚に集約。視聴者の保存欲を喚起

### バズ向け言葉のストック（Creator・Planner共有）

**断定フレーズ**
- 「ハッキリ言います」「結論から言います」「断言できます」

**読者の心の声代弁**
- 「『えっ、◯◯？怖い！』と思いますよね？」
- 「『◯◯すればいいんじゃないの？』って思いますよね？」

**二項対立フレーム**
- 攻め vs 守り／貯める呪い vs 使う勇気／数字 vs 人生／顕在 vs 潜在

**強い名詞化**（オリジナル命名のヒント）
- 「◯◯マシーン」「心の◯◯」「◯◯資金」「◯◯の罠」「◯◯の呪い」

### 構成テンプレ（さやか型・25分尺）

```
0:00〜0:45   フック（断言＋損失額＋価値の約束）
0:45〜1:30   自己紹介＋共感（権威付け1分以内）
1:30〜2:30   顕在ニーズ提示→潜在ニーズへの裏返し
2:30〜14:00  本編：第1章→第2章→第3章（各章テロップ＋比喩＋シミュレーション）
14:00〜16:00 転換点：失敗談・視聴者Q&Aで信頼の谷を作る
16:00〜20:00 マインド編（哲学・人生観に昇華）
20:00〜23:00 3点まとめ（スクショされるスライド）
23:00〜25:00 CTA（具体的ギフト＋LINE誘導＋次回予告）
```

### 既存テンプレ（15分尺）との使い分け

| 動画タイプ | 戦略 | 推奨尺 | テンプレ |
|---|---|---|---|
| 教育・知識提供（深掘り型） | バズり寄り | 15分 | 上記「構成テンプレート」 |
| バズ狙い・新規視聴者獲得 | バズり型 | 20〜25分 | バズ強化版テンプレ（さやか型） |
| シリーズ第N弾・既存ファン向け | 安定運用 | 12〜15分 | 既存テンプレ（簡略版） |
| 比較検討層への網羅情報 | **ロングテール型** | 10〜15分 | 後述「ロングテール型テンプレ」 |

### NG判定（バズ動画と比べて欠けがちな項目）

以下はCriticの審査で**バズ狙い動画では即リテイク**:
- 冒頭の損失額・数字インパクトなし
- 権威付けなし／弱い
- オリジナル比喩・命名なし
- 失敗談・本音トーンなし
- テロップ／BGM／カメラワーク指示なし
- CTAが「いいね・登録」のみで具体的ギフトなし

## 夫婦掛け合い型テンプレ（パパママ社オリジナル形式／2026-05-11追加）

参照: `Workspace/Output/AgentOutput/バズ台本分析_20260511.md` の第7章

独白型（さやか型）と並ぶ第2の主力フォーマット。**初心者・40〜50代女性向けには本テンプレを優先**。

### キャラ設定（絶対遵守）

| キャラ | 役割 | 語尾・口調の例 |
|---|---|---|
| パパ | 専門知識＋ツッコミ役 | 「〜だよね」「〜なんだよ」「えええっ！？」「〜なんですけど！」 |
| ママ | 天然＋主婦目線＋視聴者代理人 | 「〜だわ」「〜なのよ」「〜じゃない？」「〜かしら」 |

**Critic審査**: 章ごとに語尾を抽出し、混在していたら即リテイク。

### 必須要素チェックリスト（10要素＋夫婦型固有）

10要素は独白型と共通。加えて以下を必須化:

| # | 要素 | OKライン |
|---|---|---|
| A | キャラ語尾の一貫性 | パパ・ママそれぞれの語尾が章を跨いでブレない |
| B | 身体感覚表現 5種類以上 | 胃がキリキリ／冷や汗／目が点／肩こわばる／胸をなでおろす など |
| C | 3段階説明法 | 専門用語 → 平易な言い換え → 具体例（生活シーン） |
| D | 「自分ごと化」の生活シーン | スーパー／バーゲン／ママ友／カフェ／家計／子の学費 など |
| E | ボケ→ツッコミ→深化→納得の4拍子 | 1セクションに最低1ループ |
| F | スライド表示・非表示指示 | 【表示：◯◯.svg】【非表示：◯◯.svg】を台本に明記 |
| G | お客さん事例の配置 | 「実践アドバイス」セクションに置く（本編途中はNG） |
| H | オチ設計 | 大胆な提案＋ノリで乗っかる3段流れ（旅行・夢など） |

### 構成テンプレ（夫婦掛け合い型・12〜15分尺）

```
00:00:00  アテンショングラバー（ママの「大変！」＋パパの驚き＋実績グラフ）
00:00:15  導入（テーマ提示＋ママの「そもそも◯◯って？」で3段階説明法発動）
00:01:30  本題（結果発表＋下落時の不安描写＋理解の深化）
00:08:30  実践アドバイス（お客さん事例をここで挿入）
00:10:30  まとめ＋オチ（大胆提案＋夫婦の協力宣言）
```

### バズ向け言葉のストック（夫婦型）

**ママの天然ボケ**
- 「カニの缶詰みたいな名前よね？」「ブラックフライデー」「YDK」

**パパのツッコミ**
- 「えええっ！？」「カニの缶詰じゃないんですけど！」「ブラックマンデーね、ブラックフライデーは年末のセール」

**ママの自前比喩**（パパが「うまい！」と褒める設計）
- 「株の幕の内弁当」「デパートのバーゲンセール」「ジェットコースター」「最強のお守り」

**身体感覚フレーズ（最低5種類混ぜる）**
- 胃がキリキリ／冷や汗／顔から血の気が引く／目が点になる／肩がこわばる／ほっぺたが緩む／胸をなでおろす／頭がスッキリ／目がキラキラ／心臓がバクバク

### NG判定（夫婦掛け合い型）

- パパ・ママの語尾が混在 → 即リテイク
- ママが最初から賢すぎる／パパが説教調 → リテイク（成長カーブが消える）
- 身体感覚表現が3種類以下 → リテイク
- 専門用語をパパが一方的に説明（3段階説明法未使用） → リテイク
- スライド指示が台本にない → Editorに丸投げ状態でNG
- オチが「コツコツ続けましょう」で平凡に終わる → 大胆提案に書き換え

## さやか007型・突き抜けTTPチェックリスト（2026-05-11追加／最優先テンプレ）

参照: `Workspace/Output/AgentOutput/バズ台本分析_20260511.md`

**位置づけ**: バズり型の中でも「突き抜けた1本」を狙う際の最上位テンプレ。
通常のバズり型は10要素を満たせばOKだが、本テンプレは**さやか007のような爆発的バズを再現するための必須10要素**。Planner提出時にこれを満たしているか必ず自己チェックし、Criticは1項目でも未達なら差し戻し。

### TTP必須10要素

| # | 要素 | OKライン | NG例 |
|---|---|---|---|
| 1 | タイトル4点盛り | 旬KW×希少な切り口×損失額×負の命名×解決の約束 を1タイトルに | 「NISAを解説」だけ |
| 2 | 市場の空白宣言 | フックで「誰も教えていない◯◯」と明言 | 一般論で入る |
| 3 | 二段ロケット構造 | 技術編→失敗談（転換点）→マインド編 | 数字の話だけで終わる |
| 4 | オリジナル命名3個以上 | 「◯◯の呪い／◯◯マシーン／心の◯◯／◯◯資金」テンプレで作る | 一般名詞のまま |
| 5 | 常識の逆張り3回 | 各章で「世間はAと言うが実はB」を1つずつ | 主張がフラット |
| 6 | 失敗談の3点セット | 行動描写×固有金額×当時の心の声 | 抽象的な反省 |
| 7 | 数字に出典1個 | 大学／歴史的事象／統計を必ず添える | 数字だけ羅列 |
| 8 | 中盤に仮想Q&A | 「Q: ◯◯と不安です」を1つ挿入し共感で引き戻す | 中盤に山場なし |
| 9 | 引用されたい一行 | 後半に名言を1つ仕込む（サムネに使える強度） | 名言ゼロ |
| 10 | 低コストCTA | コメント欄に絵文字1個指定（「👍」など） | 「コメント書いてね」のみ |

### 命名フレームのストック（Planner用）

オリジナル命名を3個以上作る際、以下のテンプレから選ぶ:

- **◯◯の呪い** （例：貯める呪い、節約の呪い、複利の呪い）
- **◯◯マシーン** （例：貯金マシーン、節税マシーン）
- **心の◯◯** （例：心の負債、心の貯金、心のインフレ）
- **◯◯資金** （例：ダム資金、避難資金、種銭資金）
- **死ぬ時に◯◯** （例：死ぬ時に一番金持ち、死ぬ時に一番自由）
- **◯◯の罠** （例：18倍の罠、非課税の罠）
- **◯◯の黄金律** （例：売る順番の黄金律）
- **◯◯ルール** （例：4％ルール、5年ルール）

### 「常識の逆張り」ストック（チャンネルテーマ別）

| 一般常識 | 逆張り主張の型 |
|---|---|
| NISA非課税が最強 | 売る順番を間違えると非課税の意味がない |
| 定額取り崩しが安心 | 定額は暴落時に自滅する |
| 貯金は美徳 | 貯めすぎは「心の負債」を増やす |
| 早く始めるほど良い | 順番と出口を決めずに始めるな |
| 分散すれば安心 | 分散しても出口設計を間違えると損 |

### 引用されたい一行のストック

- 「お金はハサミと同じ。持っているだけでは何も切れません」
- 「お金を『経験』に交換する勇気」
- 「今日が人生で一番若い日です」
- 「死ぬ時に一番金持ちは計算ミス」
- 「不安を消すのは『残高』ではなく『納得感』」

→ **新作にも1動画1つは必ず仕込む**。

### 運用ルール

1. **Planner**: 企画書提出時に本チェックリスト10項目すべてに○/×を自己採点して添付
2. **FP**: 「数字に出典1個」項目は監修時に必ず出典の正確性を確認
3. **Critic**: 1項目でも×なら差し戻し（バズ狙い動画のみ）
4. **Slide_Designer**: 「引用されたい一行」をスクショされるスライドに必ず1枚作る
5. **SNS_Manager**: 投稿時、命名フレーズと一行名言を概要欄／ハッシュタグに展開
6. **社長**: 公開後48hで初動再生数をレビューし、未達なら未達項目を逆算してフィードバック

### 適用優先度

| 動画種別 | 適用 |
|---|---|
| バズり狙いの主軸動画 | **本チェックリストを最優先で適用** |
| シリーズ第N弾（既存ファン向け） | 任意（命名と一行は必須） |
| ロングテール型 | 適用外（戦略が異なる） |

## ロングテール型テンプレ（2026-05-11追加）

参照: `Workspace/Output/AgentOutput/バズ台本分析_20260511.md` の第5・8章

**バズり型とは別物の戦略**。初動再生数を狙わず、90日〜12ヶ月かけて検索流入で再生を積み、最終的にLINE登録などCV単価で回収するモデル。

### バズり型との設計差（再掲・絶対認識すること）

| 項目 | バズり型 | ロングテール型 |
|---|---|---|
| 評価期間 | 公開後48〜72時間 | 公開後3〜12ヶ月 |
| KPI | 初動再生数／平均視聴時間 | 90日累積再生／検索流入比率／LINE登録CV |
| タイトル | 強い断言・損失額・煽り | 検索語を素直に並べる |
| サムネ | 表情・矢印・赤文字 | キーワード視認性重視 |
| フック | 冒頭3秒で「敵」を立てる | テーマと結論の予告で十分 |
| 比喩・命名 | オリジナル概念を1〜2個 | 不要（検索ノイズになる） |
| 失敗談・本音 | 中盤に必須 | 不要 |
| CTA | 具体的ギフト＋LINE誘導 | 個別相談LINEで深いCV |

### ロングテール型の構成テンプレ（PASBECONA型・10〜15分）

```
00:00〜00:30  概要紹介（テーマと検索ニーズの一致を即時提示）
00:30〜01:00  タイトル回収（結論を先出し）
01:00〜02:00  問題提起（◯◯のリスク・落とし穴）
02:00〜03:30  問題の拡大（なぜ知らないとマズいか）
03:30〜04:30  解決策の予告（◯◯すれば回避できる）
04:30〜05:30  変革と証明（実例・お客様事例）
05:30〜09:00  本編（結論→理由→具体例→結論のサンドイッチ）
09:00〜11:00  両論併記（メリットだけでなくデメリットも）
11:00〜13:00  実践アドバイス（具体的な行動指針）
13:00〜15:00  感情メッセージ＋復習＋CTA（LINE個別相談へ）
```

### 必須要素チェックリスト（ロングテール型）

| # | 要素 | OKライン |
|---|---|---|
| 1 | 検索キーワードの網羅 | タイトル＋概要欄＋本文に、想定検索語を3〜5回自然に登場させる |
| 2 | 中立トーン | 「◯◯をやめろ」ではなく「メリットとデメリットを知ろう」 |

| 7 | LINE個別相談への着地 | 視聴後の自然なCV導線（深い相談を獲得） |

### NG判定（ロングテール型）

- タイトルに過度な煽りワード（「絶対」「最強」「危険」を多用） → SEO評価下がる
- 比喩・オリジナル命名で検索語を置き換える → 検索ノイズになりNG
- 一方的にバイアスのかかった結論 → 「中立を求める比較検討層」が離脱
- 失敗談・本音トーン → ロングテール型ではノイズ
- 初動再生数で評価 → 90日後に再評価すること
