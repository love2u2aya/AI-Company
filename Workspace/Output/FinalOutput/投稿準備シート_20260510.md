## 1. YouTubeタイトル3案（A/Bテスト用）

YouTube Studio のタイトルA/Bテスト機能に3案を同時登録する。
サムネイルはA/Bテストなし・Designerの1案を固定使用。

| 案 | タイトル | 狙い | 文字数 |
|---|---|---|---|
| **案A（推奨メイン）** | 退職金2,000万円。銀行に行く前にこの動画を見てください | 行動喚起 × タイムリー性・損失回避 | 28文字 |
| **案B** | 住宅ローンを定年前に完済したいなら、この順番で考えてください。金利1.5%未満・以上で答えが変わります | 具体的判断基準 × 検索流入 | 47文字 |
| **案C** | 再雇用で働くなら知っておくべき年金の話。月50万円の壁を超えると年金が消えます | 在職老齢年金の盲点 × 損失回避 | 41文字 |

### 各案の設計意図

- **案A（推奨メイン）**: 「銀行に行く前に」というフレーズが退職直後の行動タイミングに直撃する。退職金2,000万円という具体的な金額が自己投影を促し、クリック衝動が最も強い構成。Plannerの第二推薦案③のタイトル案②と同一。サムネイルとの「退職金2,000万円」訴求で一貫性を持たせる。
- **案B（検索流入型）**: 「住宅ローン 定年前 完済」「金利 繰上返済」など長尾キーワードの検索流入を狙う。日銀利上げ局面で検索数が急増中のキーワードを冒頭に置く。情報収集フェーズの視聴者層を取り込む。
- **案C（損失回避型）**: 「年金が消える」という強い損失回避フレームで在職老齢年金の認知層にリーチ。「月50万円の壁」という2024年改正後の最新基準額を使い、古い情報（48万円）で止まっている視聴者に情報更新の動機を与える。

## 4. 投稿推奨時間帯

| 項目 | 推奨設定 |
|---|---|
| **推奨曜日** | 土曜日 または 日曜日 |
| **推奨時間** | 20:00〜21:00（JST） |
| **次点候補** | 平日（水〜木）21:00〜22:00（JST） |

### 理由

- **ターゲット層（50代・会社員）の視聴行動**: 平日夜は21時以降でも仕事の疲れで集中力が低下するが、週末20〜21時は「今日時間があるから調べよう」という能動的な視聴モードに入りやすい。退職金・年金・住宅ローンは「ゆっくり考えたい」コンテンツのため週末視聴との親和性が高い。
- **前回iDeCo動画との連続性**: iDeCo動画の投稿曜日・時間帯を踏襲することで、シリーズとして連続視聴している視聴者の習慣に合わせる。前回動画の視聴完了後に本動画が自動再生・推奨される確率を高める。
- **競合動画との差別化**: 金融・投資系チャンネルの多くは平日夜（21〜23時）に投稿が集中する。週末20〜21時は競合投稿が少なく、初動インプレッションを取りやすい時間帯。
- **アルゴリズム上の初動設計**: YouTubeは投稿後48時間のエンゲージメント率（CTR・視聴維持率・高評価・コメント）を重視して検索表示順位を決定する。週末夜は視聴セッション時間が長く、エンゲージメントが蓄積しやすいタイミング。

## 5. 初動48時間モニタリング計画

### 確認タイミングとチェック内容

| タイミング | 確認内容 | 対応フラグ |
|---|---|---|
| **投稿直後（0〜30分）** | 動画・概要欄・タグの設定ミス最終確認。クロスリンク（前回iDeCo動画URL）が正しく機能するか確認 | 設定ミスがあれば即修正 |
| **投稿6時間後** | インプレッション数・CTR・初速再生数を確認。前回iDeCo動画の投稿6時間後データと比較 | CTR 3%未満 → 翌朝サムネイル差し替えを検討 |
| **投稿24時間後** | CTR・視聴維持率・コメント内容・タイトルA/Bテスト初期データを確認。勝利タイトルの傾向を把握 | アラートライン到達時は対応フロー参照 |
| **投稿48時間後** | 全指標の総合評価。社長への初動レポート提出。次回動画・SNS施策の判断材料として整理 | AgentOutputにレポートを保存 |

### 確認指標と目標値（SNSスキル基準準拠）

| 指標 | 目標ライン | アラートライン（要対応） |
|---|---|---|
| CTR（クリック率） | **5%以上** | 3%未満 → タイトルまたはサムネイル見直し |
| 視聴維持率（平均） | **40%以上** | 30%未満 → 冒頭1分（つかみ）の構成見直し |
| インプレッション数 | 前回iDeCo動画比 **100%以上** | 50%未満 → タグ・投稿時間を見直し |
| コメント率 | 再生数の0.5%以上 | コメントゼロ → CTAの見直し・固定コメント設置検討 |

### 注目コメントのモニタリングポイント

本動画では以下のコメントが集まりやすく、次回企画の判断材料になる。24時間後に確認して傾向を記録する。

- 「銀行に行って退職金プランを勧められた」「既にやってしまった」系の実体験コメント → 罠②の共感度測定
- 「自分の金利は何%だから繰上返済すべきか」という質問コメント → 罠①の視聴者の関心測定
- 「在職老齢年金の基準額を知らなかった」系のコメント → 罠③の情報提供効果測定
- iDeCo動画への言及・シリーズ感のコメント → クロスリンク施策の効果測定

### アラートライン到達時の対応フロー

```
CTR 3%未満（24時間時点）
  └─ サムネイルの文言・色調を変更 → Designerへ差し替え依頼
  └─ タイトルA/BテストのC案への切り替えを検討
  └─ 「退職金2,000万円」という数字を大きくしたサムネイル案をDesignerに追加発注

視聴維持率 30%未満（48時間時点）
  └─ 冒頭1分（退職後に判断力が下がる理由のパート）の簡潔化を次回制作に反映
  └─ Plannerにフィードバックして次回動画のつかみ設計を改善

インプレッション 50%未満（24時間時点）
  └─ ハッシュタグを「#退職金運用」「#定年」「#セカンドライフ」に変更
  └─ 投稿時間帯を次回は平日21時に変更して検証
```

## 6. 前回動画（iDeCo）との概要欄クロスリンク設置方法

### 設置場所と記載内容

概要欄の「前回動画」セクションに以下を記載する（概要欄のテンプレート参照）。

```
━━━━━━ 前回動画 ━━━━━━
▶ iDeCoを増額すると損する人がいる「逆転の税負担問題」
→【前回動画（企画_20260509b.md対応動画）のYouTube URLをここに記載】
iDeCoと退職金の受取タイミング問題は前回動画で詳しく解説しています。
本動画と合わせてご覧いただくと定年前5年の全体設計が見えてきます。
```

### 前回動画（iDeCo）の概要欄にも逆リンクを追記する

前回iDeCo動画の概要欄の末尾に以下を追記して双方向リンクにする。

```
━━━━━━ 続編動画 ━━━━━━
▶ 退職金2,000万円、銀行に行く前に見てください（住宅ローン・退職金・在職年金の3つの罠）
→【本動画のYouTube URLをここに記載】
iDeCo以外の定年前5年の落とし穴（住宅ローン繰上返済・退職金一括投資・在職老齢年金）を
解説しています。本動画と合わせてご覧ください。
```

### エンドカードへの設置

動画内14:30〜15:00のエンドカードに「前回動画（iDeCo）サムネイル」を設置する（ナレーション原稿_20260510.mdの編集指示に記載済み）。YouTube Studio のエンドカード編集画面で「前回動画を追加」を選択し、iDeCo動画を指定する。

### クロスリンクの効果確認方法

48時間後の初動レポートで、以下をYouTube Studioのアナリティクス（「トラフィックソース」タブ）で確認する。

- 「関連動画」からの流入数
- 「エンドカード」からの流入数
- 前回iDeCo動画からの視聴者がどの割合で本動画に流入しているか

## 7. 投稿前チェックリスト

### 動画ファイル
- [ ] 動画ファイルの書き出し品質：1080p以上、アスペクト比16:9
- [ ] 冒頭・末尾に余計な無音・ブラックアウトがないか確認
- [ ] BGMの音量バランス（ナレーションと干渉していないか）確認
- [ ] テロップの誤字脱字・数値の正確性を再確認（「360万円」「43万円 vs 505万円」「276万円」「1.5%・2%・3%」「月28万円・50万円」等）
- [ ] 「スクショ推奨」テロップが3分割設計・やってはいけない3点のスライドに入っているか確認

### タイトル・概要欄・タグ
- [ ] タイトル3案（案A・B・C）をYouTube Studioに正しく登録したか
- [ ] 概要欄の冒頭3行がモバイルで途切れない内容になっているか

### サムネイル
- [ ] Designerから納品されたサムネイルを設定済みか（A/Bテストなし・1案固定）

- [ ] 収益化設定（広告の種類・スキップ可否）を確認したか
