## 1. YouTubeタイトル3案（A/Bテスト用）

YouTube Studio のタイトルA/Bテスト機能に3案を同時登録する。

| 案 | タイトル | 狙い | 文字数 |
|---|---|---|---|
| **案A** | iDeCo月6.2万円フルで入れた人、退職金と同時受取で200〜300万円損します | 損失回避 × 具体的な数字 | 40文字 |
| **案B** | 「iDeCo上限3倍」で喜んだ人が定年時に気づく200〜300万円の誤算 | 意外性・逆張り × 具体的な数字 | 38文字 |
| **案C** | 2026年iDeCo改正の落とし穴：増額すると退職所得控除が消える仕組みを知っていますか | 意外性 × 時事性・タイムリー感 | 46文字 |

### 各案の設計意図

- **案A（推奨メイン）**: 「損する」という損失回避フレームに「200〜300万円」の具体数字を組み合わせ、クリック衝動が最も強い構成。ターゲット（増額を検討中の50代会社員）に直撃する。
- **案B（逆張り型）**: 「3倍と喜んだ」という前提を逆転させる意外性で興味を引く。タイトルが短くモバイルでも視認しやすい。
- **案C（情報型）**: 「2026年改正」というタイムリーキーワードを冒頭に置き、検索流入を狙う。情報収集層・慎重派に刺さりやすい。

## 4. 投稿推奨時間帯

| 項目 | 推奨設定 |
|---|---|
| **推奨曜日** | 土曜日 または 日曜日 |
| **推奨時間** | 20:00〜21:00（JST） |

### 理由

- **ターゲット層（50代・会社員）の行動パターン**: 平日夜（21時以降）より週末の夜が視聴ピーク。仕事の疲れが落ち着き、お金や老後に関する情報をゆっくり調べやすい時間帯。
- **競合動画との差別化**: 金融・投資系チャンネルの多くは平日夜に投稿が集中するため、週末投稿で初動インプレッションが取りやすい。
- **YouTube検索アルゴリズム**: 投稿から48時間のエンゲージメント率が検索表示順位に影響する。週末20〜21時は視聴セッションが長く、エンゲージメント（高評価・コメント・保存）が蓄積しやすい。
- **「2026年iDeCo改正」の鮮度**: 改正施行直後の旬なコンテンツのため、なるべく早い投稿が望ましい。動画完成次第、次の土日または日曜を狙う。

## 5. 初動48時間モニタリング計画

### 確認タイミング

| タイミング | 確認内容 |
|---|---|
| 投稿直後（0〜1時間） | 動画・概要欄・タグの設定ミスがないか最終確認 |
| 投稿6時間後 | インプレッション数・CTR・初速再生数の確認 |
| 投稿24時間後 | CTR・視聴維持率・コメント内容の確認。タイトルA/Bテストの初期データ収集 |
| 投稿48時間後 | 全指標の総合評価。次回動画・SNS施策の判断材料としてまとめる |

### 確認項目と目標値（SNSスキル基準準拠）

| 指標 | 目標ライン | アラートライン（要対応） |
|---|---|---|
| CTR（クリック率） | **5%以上** | 3%未満 → タイトルまたはサムネイル見直し |
| 視聴維持率（平均） | **40%以上** | 30%未満 → 冒頭1分の構成見直し |
| インプレッション数 | 前回動画比 **100%以上** | 50%未満 → タグ・投稿時間を見直し |
| コメント率 | 再生数の0.5%以上 | コメントゼロ → CTAの見直し・固定コメント設置検討 |

### アラートライン到達時の対応フロー

```
CTR 3%未満（24時間時点）
  └─ サムネイルの文言・色調を変更 → Designerへ差し替え依頼
  └─ タイトルA/BテストのC案への切り替えを検討

視聴維持率 30%未満（48時間時点）
  └─ 冒頭1分（つかみ）の見直しを次回制作に反映 → Plannerにフィードバック

インプレッション 50%未満（24時間時点）
  └─ ハッシュタグを「#iDeCo2026」「#節税」に変更
  └─ 投稿時間帯を次回は平日21時に変更して検証
```

## 6. 投稿前チェックリスト

### 動画ファイル
- [ ] 動画ファイルの書き出し品質：1080p以上、アスペクト比16:9
- [ ] 冒頭・末尾に余計な無音・ブラックアウトがないか確認
- [ ] BGMの音量バランス（ナレーションと干渉していないか）確認
- [ ] テロップの誤字脱字・数値の正確性（特に「200〜300万円」「1,850万円」等）を再確認

### タイトル・概要欄・タグ
- [ ] タイトル3案をYouTube Studioに正しく登録したか
- [ ] 概要欄の冒頭3行がモバイルで途切れない内容になっているか
- [ ] タイムコード付き目次が実際の動画尺と一致しているか
- [ ] ハッシュタグ6個を概要欄末尾に追記したか
- [ ] 免責事項が概要欄末尾に記載されているか

### サムネイル
- [ ] Designerから納品されたサムネイルを設定済みか（A/Bテストなし・1案固定）
- [ ] サムネイルが1280×720px以上かつ2MB以下か
- [ ] サムネイルのテキストがモバイル表示でも判読できるか

### 設定・その他
- [ ] 公開設定：予約投稿（土日20:00〜21:00）になっているか
- [ ] カテゴリ：「ノウハウ・スタイル」または「教育」に設定したか
- [ ] 字幕（自動生成）の有効化を確認したか
- [ ] 終了画面・カード（次回動画・チャンネル登録）を設定したか
- [ ] 収益化設定（広告の種類・スキップ可否）を確認したか
- [ ] コミュニティガイドライン上の問題がないか（金融情報の免責事項）

### 投稿直前
- [ ] プレビュー再生で映像・音声・テロップの最終確認
- [ ] 概要欄のリンク（要点チェックリスト等）が正しく機能するか確認
- [ ] 社長・秘書への投稿完了連絡の準備（LINE）
