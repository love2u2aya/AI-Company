**共通ルール**: 2本で色調とレイアウトを揃える（背景ネイビー #0D1B3E、強調は黄色 #F1C40F、警告は赤 #E02020）。左上に「前編」「後編」バッジ

## 前編

**想定タイトル**: iDeCo、55歳で始めると63歳まで受け取れない｜12月改正と50代の落とし穴

### ラフA ―「数字で警告」型（推奨）
- **キャッチコピー**: `55歳→63歳`（大きく、黄色の数字。矢印は赤）
- **サブコピー**: `iDeCoの落とし穴`（白抜き・黒縁）
- **右上バッジ**: `12月改正`（赤い丸バッジ）
- **人物**: 左端に登場者。眉をひそめて数字を指差す
```
┌──────────────────────────────────┐
│[前編]                  (12月改正) │
│                                  │
│ [顔]   55歳 ──→ 63歳             │
│ 指差し  （黄色・特大／矢印は赤）    │
│                                  │
│        iDeCoの落とし穴            │
└──────────────────────────────────┘
```

### ラフB ―「上限アップ＋でも」型
- **キャッチコピー**: `月6.2万円に`（黄色・特大）
- **サブコピー**: `でも落とし穴2つ`（赤帯に白文字）
- 6.2万円の横に上向き矢印、その下に「⚠」マーク2つ
- 競合の「62,000円時代」系と並んでも、「でも」で差がつく

## 後編

**想定タイトル**: 専業主婦のiDeCoは節税ゼロ？退職金がある夫と妻の正しい分け方

### ラフA ―「夫婦の左右分割」型（推奨）
- 画面を左右に分割。左＝夫、右＝妻のイラスト（または登場者2人）
- **夫側の文字**: `控除が埋まる`（赤）
- **妻側の文字**: `節税0円？`（黄色・特大。ここが目線の中心）
- **下部の帯**: `夫婦の正しい分け方`（白文字・ネイビー帯）
```
┌──────────────────────────────────┐
│[後編]                            │
│   [夫]          │    [妻]         │
│  控除が埋まる   │   節税0円？      │
│   （赤）        │  （黄色・特大）   │
│─────────────────────────────────│
│        夫婦の正しい分け方          │
└──────────────────────────────────┘
```

### ラフB ―「3つの箱」型
- 3つの箱を横並び：`夫 iDeCo`／`妻 NISA`／`預金`
- **キャッチコピー**: `iDeCoは夫だけ？`
- 情報は分かりやすいが、ラフAより目を引く力は弱い

---

## Designer所見
- 前編はラフA（55歳→63歳）が最も強い。数字だけで「自分のことだ」と分かる
- 後編はラフA（節税0円？）。疑問形で意外性があり、Criticの推奨タイトルとも一致する
- 本番制作はGPT-image-2で、社長承認①の後に2〜3案に仕上げる
