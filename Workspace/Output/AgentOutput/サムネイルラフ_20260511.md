## 1. サムネイルコンセプト

### 核心訴求

「同じ生活費なのに老後の必要額が**5倍違う**」という数字の衝撃を、視覚的な対比構造でそのまま叩きつける。視聴者（55歳前後・共働きまたは専業主婦世帯）が「自分はどっちだ？」と0.3秒で自己投影できる設計。

---

### 感情誘導の流れ（3段階）

```
[段階1] バッジ（深紅）が「警告」を発する → 視線をつかむ
[段階2] 「800万円」「4,000万円」の数字対比が「意外性」を与える → 驚き・疑問
[段階3] 「同じ生活費なのに」というコピーが「なぜ？」を呼び起こす → クリック動機
```

---

### 構図・レイアウト設計

前回2本は「1つの大きな数字 + 行動フレーズ」の縦積み構成。今回は「数字の**対比**」が最大の武器なので、上下2ゾーンに数字を分割配置する新構成を採用する。ただしフォント・色・バッジ・背景はシリーズ規則を完全継承する。

```
┌──────────────────────────────────────────────────────┐  ← Y=0
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                  │
│▓  老後の必要額　衝撃の差（白・36px）     ▓              │  ← Y=40px（バッジ上端）
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                  │  ← Y=104px（バッジ下端）
│                                                      │
│  共働き（白・72px）                                   │  ← Y=130px
│  800万円（黄・150px）                                 │  ← Y=200px
│                                                      │
│  ─────────────────────── （区切り線・深紅）             │  ← Y=400px
│                                                      │
│  専業主婦（白・72px）                                  │  ← Y=430px
│  4,000万円（黄・110px）                               │  ← Y=500px
│                                                      │
│  同じ生活費なのになぜ5倍違うのか（白・44px）             │  ← Y=640px
└──────────────────────────────────────────────────────┘  ← Y=720px
```

### カラー設計（シリーズ継承）

| 役割 | カラーコード | 継承元との関係 |
|---|---|---|
| 背景ベース | `#080808` | 前回2本と**完全一致**。シリーズの「黒」を継続 |
| 背景ビネット（左右コーナー） | `#1A0005` 〜 `#080808` | 第1弾・第2弾のビネット色に戻す。深紅系ビネットは「老後の危機感」テーマに整合する |
| メインアクセント（バッジ・区切り線） | `#B01020` | 前回2本と**完全一致**。深紅＝「警告」シリーズ文法 |
| バッジテキスト | `#FFFFFF` | 変更なし |
| 数字「800万円」「4,000万円」 | `#FFD700` | 前回2本と**完全一致**。「数字＝黄色」シリーズ文法 |
| カテゴリラベル「共働き」「専業主婦」 | `#F0F0F0` | 前回2本のサブコピー色と同一 |
| サブコピー「同じ生活費なのになぜ5倍違うのか」 | `#F0F0F0` | 同上 |
| 背景グレイン（ノイズ） | 8%不透明度 | 前回2本と**完全一致** |

---

### フォント設計

| テキスト要素 | フォント | ウェイト | サイズ（1280px基準） | 字間 |
|---|---|---|---|---|
| バッジ「老後の必要額　衝撃の差」 | Noto Sans JP | Black（900） | 36px | -1px |
| カテゴリラベル「共働き」「専業主婦」 | Noto Sans JP | Black（900） | 72px | -2px |
| メイン数字「800万円」（上段・強調大） | Noto Sans JP | Black（900） | **150px** | -4px |
| メイン数字「4,000万円」（下段・やや小） | Noto Sans JP | Black（900） | **110px** | -3px |
| サブコピー「同じ生活費なのになぜ5倍違うのか」 | Noto Sans JP | Bold（700） | 44px | -1px |

**フォントサイズの設計意図：**
- 「800万円（150px）」を上段に大きく配置し、「意外に少ない！」という驚きを先に与える
- 「4,000万円（110px）」は下段でやや小さく配置。視覚的な「下から重くなる」圧迫感が5倍の格差感を演出する
- 2つの数字のサイズ差（150px vs 110px）は「小さな数字 vs 大きな数字」という直感と逆転させており、「800万円の方が大きく見える」ことがさらなる意外性を生む
- サブコピー44pxは前回完成版の52pxより8px小さく、縮小表示ではほぼ読めないが存在として機能する

---

### 区切り線の設計

- `#B01020`（深紅）の水平ライン、高さ3px、X=40px〜X=1240px（左右40pxの余白を確保）
- 上下の数字ブロックを「VS構造」として視覚的に分断する役割
- 深紅は「バッジと同じ警告色」で「この差が問題だ」という感情を強化する

LAYOUT — all text LEFT-ALIGNED, text starting at X=40px from left edge, top to bottom:

[DIVIDER LINE — Visual VS separator]
- A horizontal line at Y=405px. Color: deep crimson (#B01020). Height: 3px. Starts at X=40px, ends at X=1240px. This line acts as a VS divider between the two number zones.

[LOWER NUMBER ZONE — "Homemaker household" block, dominant lower half]

OVERALL FEEL:
The design must feel like a continuation of an established financial warning series on YouTube — characterized by near-black backgrounds, deep crimson badge labels, and golden yellow numbers. The dominant impression in the first 0.3 seconds must be: a clear contrast between two golden-yellow numbers (800万円 above, 4,000万円 below) separated by a crimson dividing line, with a category label for each. The design poses a visual question: "why are these two numbers so different?" The tone is that of an authoritative financial alert from a trusted advisor — serious, urgent, but not cheap clickbait. Ultra-high contrast throughout. No gradients on text. No glow or drop shadow effects. No decorative borders. Pure typography on near-black. The two-number split-zone layout is the key departure from previous episodes, while maintaining the same color system and typographic rules.

## 3. 文字テロップ案

### バッジ（上部・深紅背景）

```
老後の必要額　衝撃の差
```

- 配置：左上（左端ブリード）、Y=40px（上端）、高さ64px固定
- 背景色：`#B01020`（矩形・ブリードラベル、角丸なし）
- 文字色：`#FFFFFF`
- フォント：Noto Sans JP Black、36px、字間-1px
- **設計理由**：「老後の必要額」という今回のテーマを直接提示しつつ、「衝撃の差」で視聴者の好奇心を起動する。前回の「退職金受取直前　警告」「2026年改正　落とし穴」と同じ「テーマ＋感情ワード」の2語構成でシリーズ文法を維持する。

---

- テキストシャドウ：なし
- 付属カテゴリラベル（上の行・Y=130px）：「共働き」、`#F0F0F0`、Black、72px

### サブコピー（下部・1行）

```

```

- 配置：左揃え（X=40px）、Y=642px〜

### 縮小表示（120×90px）での可読性確認

| 要素 | 縮小時サイズ感 | 合格ライン |
|---|---|---|
| バッジ（深紅） | 約5px高さの深紅帯 | 「警告シグナル」色として認識できればOK |
| 「800万円」（黄・150px） | 約12px相当の黄色文字 | 「800」の3桁が黄色として視認できること（最重要） |
| 区切り線（深紅） | 約0.2〜0.3px | 見えなくてよい。上下2ブロック構造は数字の配置で伝わる |
| 「4,000万円」（黄・110px） | 約9px相当の黄色文字 | 「4,000」が別の黄色数字として識別できること |
| カテゴリラベル「共働き」「専業主婦」（白・72px） | 約6px相当 | 読めなくてよい。数字との「行セット」構造が伝わればよい |
| サブコピー（白・44px） | 約3.5px相当 | 読めなくてよい |

**最低合格ライン：「黄色の大きい数字（800万円）」と「黄色の小さい数字（4,000万円）」の2ブロック対比が、縮小状態でも「2つの異なる数字がある」と識別できること。**

## 4. 前回2本とのシリーズ連続性の設計意図

### シリーズ3本の構成と役割

| 話数 | タイトル | 数字の軸 | サムネイル特徴 |
|---|---|---|---|
| 第1弾 | iDeCo増額した人が得する話 | 「300万円」（ひとつの差額数字） | 1数字・縦積み・深紅ビネット |
| 第2弾 | 退職金2,000万円、銀行に行く前に | 「2,000万円 → 1,000万円の差」（連続性の数字） | 1数字+損失数字・縦積み・深緑ビネット |
| **第3弾（本作）** | **共働き800万円 vs 専業主婦4,000万円** | **「800万円 vs 4,000万円」（対比の数字）** | **2数字・VS対比構造・深紅ビネット（第1弾回帰）** |

### 意図的な変更点（第3弾の独自性）

| 変更点 | 前回（第2弾）との差異 | 変更理由 |
|---|---|---|
| レイアウト構造 | 縦積み1数字 → **VS対比2数字** | 「共働き vs 専業主婦」という対比が今回の最大訴求。1数字では構造が伝わらない |
| ビネット色 | `#0D1500`（深緑） → **`#1A0005`（深紅）** | 第1弾の深紅ビネットに戻すことで「老後の危機・警告」テーマの一体感を強化。第2弾は「銀行」テーマのため深緑を採用したが、本作は「計算の誤差」という内的リスクが主題のため深紅に回帰 |
| 区切り線の追加 | なし → **深紅水平ライン（Y=405px）** | VS構造を明確にする新要素。深紅を使うことでバッジと統一感を持たせる |
| 数字のサイズ差 | 単数字（前回170px） → **2数字（150px + 110px）** | 「800万円」を大きく見せることで「意外に少ない」という誤解を誘発→「4,000万円」で驚かせるという感情の2段階誘導を設計 |

---

### シリーズとしてのビジュアルジャーニー

3本を並べたとき、視聴者が感じる感情の連続性：

```
第1弾：「iDeCoで300万円も差がつくのか」→（行動動機を得る）
第2弾：「退職金2,000万円、銀行で1,000万円損するところだった」→（受け取り方を学ぶ）
第3弾：「共働き800万円 vs 専業主婦4,000万円、同じ生活費でこんなに違うのか」→（自分の数字を計算する）
```

3本を通じて「積み立て→受け取り→総合設計」という老後資産形成の全体フローが完成する設計になっており、サムネイルの視覚文法が統一されていることで「シリーズを全部見たい」という動機をチャンネルブラウジング時に自然に生み出す。

## 付記：Criticからの指摘への対応

- 「老後2,000万円問題」という文言：**バッジ・メインコピー・サブコピーのいずれにも使用していない**
- 「共働き800万円」の前提条件：サムネイルでは前提を表示する余白がないが、バッジの「衝撃の差」という文言で「これは特定の条件の下での数字だ」という含意を持たせている。Criticが求めた「本編0:30以内での前提明示」はCreatorへの制作指示に委ねる
- 禁止ワード確認：**すべてのテキスト要素に「2,000万円問題」は存在しない**
