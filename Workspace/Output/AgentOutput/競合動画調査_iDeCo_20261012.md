## 2. 伸びているテーマは4つ

1. **改正で上限アップ**（#1）：「62,000円時代」「神改正」。数字の大きさと「今からやるべき準備」を前面に出している
2. **受取時の増税・改悪**（#2）：5年ルール→10年ルールで「退職金とiDeCoの控除が取り合いになる」話。**損を避けたい気持ち**に訴えるテーマが強い
3. **50代から始める**（#3, #5）：「遅くない」「最強」「迷ったら50代開始でOK」。**当社のターゲット（50代）と完全に重なる**。2本合計で40万再生超
4. **出口戦略・税金0円**（#4, #6）：一時金と年金の組み合わせ、公的年金の前（60〜64歳）に年金形式で受け取る、など。「税金0円」「無税」という言葉で引きつけている

## 3. 各動画の中身（推定）

- **#1 62,000円時代へ**：会社員・公務員の上限が月6.2万円に。企業型DCがある人は「6.2万円−会社の掛金」が自分の枠。掛金を上げるには**自分で変更届を出す必要がある**（出さないと今の金額のまま）。引き落としは2027年1月から
- **#2 リベ大 受取時に増税？**：iDeCo一時金→退職金の順で受け取る場合、控除を満額使うための間隔が5年から10年に延びた（2026年1月以降の受取が対象）。60歳でiDeCo・65歳で退職金という従来のやり方では税負担が増える
- **#3 あえて50代から**：50代から始めても10年前後は運用できる。節税メリットは大きいが、期間が短いぶん積み上がる額には限りがある。NISAとの併用、生活防衛資金を先に確保、が定番の結論
- **#4・#6 山田真哉**：12年間の実際の運用結果を公開。一時金は退職所得控除の枠内に収め、残りを年金形式で受け取ると**税金ゼロも可能**。一時金と退職金を同じ年に受け取ると控除は1回分しか使えない点に注意
- **#5 マネーセンスカレッジ**：「10年運用できれば遅くない」。想定利回り7%（インフレ控除後5%）でシミュレーション
- **#7 中田敦彦**：iDeCoとNISAの基本比較（ショート）

## 4. 当社動画（TICKET-011）への示唆

### 競合と同じ土俵（入れないと見劣りする）
- 6.2万円への上限アップ、70歳まで加入（改正の基本）
- 10年ルール（受け取り順で税金が変わる）
- 50代からでも遅くない
- 一時金・年金の受け取り方で税金が変わる

### 競合が手薄で、当社の差別化になりそうな点（FPブリーフの独自ネタ）
タイトルから見る限り、以下を正面から扱う人気動画は見当たらなかった：

| 当社の切り口 | なぜ差別化になるか |
|---|---|
| **専業主婦の妻は節税ゼロ → 夫婦で分担（夫iDeCo・妻NISA）** | 人気動画はほぼ「個人」目線。夫婦セットの設計は少ない |
| **55歳開始だと受け取れるのは63歳から**（10年未満ルール） | 「50代から最強」系が多い中で、50代が実際にハマる落とし穴 |
| **定期預金でも節税はフルに取れる** | 「50代は運用リスクが怖い」への直接の答え |
| **節税は単利、運用は複利（ジェットコースター）** | 「すごい」と「怖い」を1つの絵で整理できる |
| **70歳（かける）と75歳（置いておく）の違い** | 改正動画が触れていても、混同しやすい点を明確に分けて語る動画は少ない |
| **公的年金の繰り下げ中にiDeCoを年金で受け取る** | 当社の過去シリーズ（繰り下げ・第5弾）と連動できる |

### タイトル・サムネの傾向
- 強い言葉が多い：「神改正」「改悪」「増税」「不要になる人」「税金0円」「最強」「もう遅いは誤解」
- 数字を入れる：「62,000円」「12年続けた結果」「300万円有利」
- 当社は「煽らない・正確」路線（FPブリーフ§9）なので、**具体的な数字と「夫婦」「50代の落とし穴」で差をつける**のが妥当
  - 例：「専業主婦の妻のiDeCoは節税ゼロ？50代夫婦の正しい分担【2026年12月改正】」
  - 例：「55歳で始めると63歳まで受け取れない｜50代のiDeCo、3つの落とし穴」
