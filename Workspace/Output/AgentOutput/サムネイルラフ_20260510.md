## 1. サムネイルコンセプト

### 核心戦略

「銀行に行こうとしている人の手を止める」という一点に全リソースを集中させる。

視聴者ペルソナは退職金が口座に振り込まれた直後、あるいは振り込まれる直前の58〜63歳。「まず銀行に相談しよう」という行動を今まさに取ろうとしているタイミングにいる。そのリアルな行動直前の文脈に直撃させるデザインにする。

---

### 色設計：シリーズカラー継承 × 部分的トーン変更

前回（黒×深紅×黄）のシリーズカラーを基本的に**継承する**。

| 役割 | カラーコード | 前回比較 | 理由 |
|---|---|---|---|
| 背景ベース | `#070808` | 前回`#080808`とほぼ同一 | シリーズの「黒背景＝信頼感・緊張感」の継続 |
| 背景ビネット | `#0D1A00`〜`#070808` | 前回：深紅寄り → 今回：深緑寄り | 「銀行」という金融機関を想起させる深緑成分を微量加える。ただし背景全体は黒が支配的なのでシリーズ感は維持される |
| メインアクセント（バッジ） | `#B01020` | 前回と同一 | シリーズの「深紅バッジ＝緊急警告シグナル」を完全継承。視聴者がシリーズだと即認識できる |
| バッジテキスト | `#FFFFFF` | 変更なし | |
| メインコピー行1（数字） | `#FFD700` | 前回と同一 | 前回の「300万円」で確立した「黄色＝重要数字」の読み替えパターンを引き継ぐ |
| メインコピー行2（動詞句） | `#F0F0F0` | 前回：黄色2行 → 今回：1行目黄色・2行目白 | 詳細後述 |
| 強調数字「2,000万円」 | `#FFD700` | 前回「300万円」と同じ処理 | 「数字＝黄色」のシリーズルールを継続 |

**なぜ2行目を白にするか：**
前回は「iDeCo増額した人／ほど損する」と2行とも黄色にして「損する」というネガワードを強調する構造だった。今回は「2,000万円（黄色・数字インパクト）／銀行に行く前に（白・行動喚起）」と分割することで、「数字で驚かせてから行動を止める」という2ステップの視覚的誘導を作る。白と黄色のコントラストが視線の流れを「金額→行動」という順番に整流する。

### 構図設計

```
┌──────────────────────────────────────────────────────┐
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                          │
│▓  退職金受取直前  警告            ▓                    │  ← 深紅バッジ（左ブリード）
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓                          │
│                                                      │
│                                                      │
│  2,000万円（黄・極大）                                 │  ← CENTER TOP
│                                                      │
│  銀行に行く前に（白・大）                               │  ← CENTER BOTTOM
│                                                      │
│  「3つの罠と手取り1,000万円の差」（白・小）              │  ← BOTTOM
└──────────────────────────────────────────────────────┘
```

**構図の狙い：**

- 画面中央上部に「2,000万円」を最大サイズで配置。サムネイル縮小状態（120×90px）でも黄色の数字が視認できるよう、他のどの要素よりも大きく設定する。
- 直下に「銀行に行く前に」を白で置くことで「この大金を銀行に持って行こうとしていた人だ」という文脈認識が瞬時に成立する。
- 前回同様、左揃えで統一。センター揃えにしない（前回との視覚的連続性維持）。
- 顔出しなし、イラストなし、写真なし。純粋なタイポグラフィ設計（前回と同一方針）。

---

### 感情訴求設計

| 視聴者の状態 | このサムネイルが与える感情 | 設計上の根拠 |
|---|---|---|
| 「退職金が入ったら銀行に行こう」と考えている | 「待って、何か見逃しているかもしれない」という軽い恐怖 | 「銀行に行く前に」という行動への割り込みフレーズ |
| 「2,000万円もある、安心だ」と感じている | 「2,000万円という大金が危険にさらされているかもしれない」 | 数字を超大きく見せることで「それだけ大きなリスクがある」と逆説的に伝える |
| 前回のiDeCo動画を見ていた視聴者 | 「またあのシリーズだ、役に立ちそう」という信頼感 | 深紅バッジ×黄色数字×黒背景のシリーズ識別子を踏襲 |

## 3. 文字テロップ案

### バッジ（上部・深紅背景）

```
退職金受取直前　警告
```

- 配置：左上（左端ブリード）、Y=40px
- 背景色：`#B01020`（矩形・ブリードラベル、角丸なし）
- 文字色：`#FFFFFF`
- フォント：Noto Sans JP Black、36px
- バッジ高さ：64px固定

**採用理由：**「2026年改正」のような年号より、「退職金受取直前」というペルソナの状況を直接指示する言葉の方が「私のことだ」という自己認識を速く起動できる。「警告」という一語で赤バッジの意味を補強。

---

### メインコピー（中央上部・黄色・1行）

```
2,000万円
```

- 配置：左揃え（X=40px）、Y=160px〜
- 文字色：`#FFD700`
- フォント：Noto Sans JP Black、160px
- テキストシャドウ：なし
- 字間：-3px

**採用理由：**「退職金2,000万円を銀行へ」というリアルな行動文脈に最も関連する数字を1行で最大化。「2,000万円」という具体金額が見えることで「自分の退職金と同じ規模感だ」という当事者意識が生まれる。サブのタイトル「銀行に行く前に」と組み合わせて初めて「2,000万円を銀行に持って行こうとしている自分」という文脈が補完される。

---

### サブコピー行1（中央下部・白・1行）

```
銀行に行く前に
```

- 配置：左揃え（X=40px）、Y=360px〜
- 文字色：`#F0F0F0`
- フォント：Noto Sans JP Black、108px
- テキストシャドウ：なし

**採用理由：**動画タイトル「退職金2,000万円。銀行に行く前にこの動画を見てください」の最もクリティカルな部分を抽出。「銀行に行く前に」というフレーズがサムネイルで視認できることで、タイトルとの二重確認効果が生まれ、クリック意向が高まる。

---

### サブコピー行2（下部・白×金）

```
3つの罠と手取り　1,000万円　の差
```

- 配置：左揃え（X=40px）、Y=580px〜
- 「3つの罠と手取り」「の差」：`#F0F0F0`、50px、Bold
- 「1,000万円」：`#FFD700`、58px、Bold（ワンサイズ大・色変え）

**採用理由：**「1,000万円の差」という損失規模を提示することで、「2,000万円を持って銀行に行ったら1,000万円損するかもしれない」というリスク認知を数字で補強。前回サムネイルの「300万円」と同じ黄色強調処理を使うことでシリーズ内の「数字＝黄色」という視覚文法が定着していく。

## 4. 前回サムネイルとのシリーズ連続性

### 共通要素（意図的に引き継いだもの）

| 要素 | 前回（iDeCo動画） | 今回（退職金動画） | 連続性の効果 |
|---|---|---|---|
| 背景色 | `#080808`（ほぼ黒） | `#070808`（ほぼ黒） | 「このシリーズだ」という即時認識 |
| 左上バッジ | 深紅`#B01020`、左ブリード、高さ64px | 同一仕様 | シリーズの「警告シグナル」として定着させる |
| バッジ内文字色 | 白`#FFFFFF` | 白`#FFFFFF` | 変更なし |
| メインコピー色 | 黄色`#FFD700` | 黄色`#FFD700`（数字部分） | 「重要情報＝黄色」のシリーズ文法 |
| テキスト配置 | 左揃え（X=40px） | 左揃え（X=40px） | フォーマットの統一感 |
| フォント | Noto Sans JP Black/Bold | Noto Sans JP Black/Bold | タイポグラフィの一貫性 |
| 背景グレイン | 8%ノイズ | 8%ノイズ | 金融書類感の演出 |
| 顔出しなし・イラストなし | 純タイポグラフィ | 純タイポグラフィ | チャンネルフォーマットの維持 |

---

### 変更点（意図的に変えたもの）と理由

| 要素 | 前回 | 今回 | 変更理由 |
|---|---|---|---|
| 背景ビネット色 | 深紅寄り（`#1A0005`） | 深緑微量混合（`#0D1A00`）| 「銀行・金融機関」を想起させる深緑成分を微量加える。ただし支配色は黒のまま維持し、シリーズ感を損なわない範囲に留める |
| メインコピーの行構成 | 黄色2行（テーマワード＋動詞） | 黄色1行（数字）＋白1行（行動喚起） | 今回は「数字の巨大感で驚かせる」→「行動を止める言葉で介入する」という2ステップの感情誘導が設計意図。2行とも黄色にすると「等価な2つのメッセージ」に見えてしまい、視線の流れが分散する |
| バッジテキスト内容 | 「2026年改正　落とし穴」 | 「退職金受取直前　警告」 | バッジは各動画のテーマに合わせて更新（シリーズ内で毎回変わることでフレッシュ感を維持しつつ、デザインフォーマットは統一） |
| 強調数字のスケール | 「300万円」70px（サブコピー内） | 「2,000万円」160px（メインコピーとして最大化） | 今回は数字自体が主役。前回は数字が「補強証拠」の役割だったが、今回は「銀行に持って行こうとしている金額」そのものが視聴者との接点になるため、最大サイズで訴求する |

### 縮小表示（120×90px）での読める要素

| 要素 | 縮小時サイズ感 | 合格基準 |
|---|---|---|
| バッジ | 深紅の帯として視認 | 「警告シグナル」の色として認識できればOK。文字は読めなくてよい |
| 「2,000万円」（黄・160px） | 約13px相当の黄色文字 | 数字の存在が認識できること（「2,000」が見えれば合格） |
| 「銀行に行く前に」（白・108px） | 約9px相当の白文字 | 「銀行」の2文字が読めること |
| サブコピー | 約4〜5px相当 | 読めなくてよい。「追加情報がある」という補助的存在として機能 |

「2,000万円」と「銀行に行く前に」の2行が縮小状態で両方認識できること = このサムネイルの最低合格ライン。

## 付記：Criticコメントへの対応

批評レポートで指摘された「案③のダークグリーン×白という企画書原案カラーだとシリーズ連続性が薄れる」という懸念に対し、本ラフでは**シリーズカラー（黒×深紅×黄）を基本維持した上で、深緑をビネットに微量混ぜる程度に留める**設計とした。企画書の「ダークグリーン×白」はあくまで方向性のメモであり、シリーズブランドの確立を優先するDesigner判断として黒基調を継続する。
