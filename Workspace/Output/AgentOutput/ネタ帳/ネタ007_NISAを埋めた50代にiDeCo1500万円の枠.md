# ネタ007｜NISAを毎年360万円埋めている50代へ：iDeCoで「もう1つの約1,500万円の枠」ができた

**登録日**: 2026-10-15
**発案**: 社長
**状態**: 未使用（ストック）
**使えそうな場所**: iDeCo改正・前編の締め／後編S19（3,600万円ライン）／単独動画1本（富裕層・50代向け）

---

## 対象の人
- 銀行のお金を、毎年NISAの上限（年360万円）まで移している50代
- 5年でNISAの1,800万円が埋まり、「この先の置き場所がない」人

## 一言でいうと
12月から、会社員のiDeCoは年74.4万円（月6.2万円×12）まで掛けられて、しかも70歳まで続けられる。今50歳なら、20年で**約1,500万円**。NISAの1,800万円に、もう1つ大きな枠が加わったと考えていい。

## 枠の大きさ（今50歳・70歳まで掛けた場合）

| | NISA | iDeCo（年74.4万円×20年） | 合計 |
|---|---|---|---|
| 1人（会社員・企業年金なし） | 1,800万円 | 約1,490万円 | **約3,290万円** |
| 夫婦とも会社員 | 3,600万円 | 約2,980万円 | **約6,580万円** |
| 夫が会社員・妻が専業主婦 | 3,600万円 | 約1,490万円＋約550万円（妻は月2.3万円のまま） | **約5,640万円** |

- これは**元本**の枠。運用で増えた分は含まない
- 夫婦で6,000万円前後の元本が非課税の口座に入り、運用で増えれば、**時価1億円がまるごとNISA＋iDeCoの中**、ということも現実に起こりうる

## 必ず添える注意（NISAと同じ「非課税」ではない）

| | NISA | iDeCo |
|---|---|---|
| 引き出し | いつでも | 60歳以降（加入期間で変わる） |
| 受け取るとき | 税金ゼロ | **退職所得控除などを超えた分に課税** |
| 売った後の枠 | 翌年戻る | 戻らない |

- iDeCoに20年掛けた場合の退職所得控除は800万円。退職金と重なった期間があれば、さらに減る（ネタ002・005）
- 1,490万円掛ければ、元本だけで控除を超える。**iDeCoは「非課税の枠」というより「税金を先送りして、受け取り方で減らす枠」**
- 受け取り方の工夫（一時金と年金形式の組み合わせ、公的年金の前に年金で受け取る）が前提（ネタ001・005）
- それでも、入れるときに20〜30%の節税、運用中は非課税、受け取りは半分課税などで軽い → 余裕資金がある人には十分得

## 条件
- 70歳まで掛けるには、老齢基礎年金とiDeCoをまだ受け取っていないこと（国民年金は繰り下げになる）
- 企業年金がある会社員は「月6.2万円−会社の掛金」なので、枠は小さくなる
- 60歳以降の掛金の節税は、その年の収入による（退職後は小さい）

## 発展：子どもへ移す（今回は詳しく話さない）
- 余裕がある人は、子どもの名義で運用することも考えられる
- ⚠ **ジュニアNISAは2023年で終了**している。代わりに、2027年から**未成年もNISAのつみたて投資枠を使える**ようになる予定（年60万円・総額600万円まで、12歳から引き出せる）→ **使う直前にFPが制度の確定内容を確認**
- 子どもへの贈与も、年110万円までなら贈与税はかからない。管理は子どもの名義・口座で（ネタ006の名義預金の注意と同じ）

## 言い回し案
「NISAに毎年360万円入れてきた方、5年で枠が埋まりますよね。12月からは、iDeCoがもう1つの大きな枠になります。月6.2万円、年74万円を、70歳まで。今50歳なら20年で約1,500万円です。NISAと合わせて、1人3,300万円近い枠。夫婦なら6,000万円前後。運用で増えれば、資産1億円がまるごと非課税の口座の中、ということも夢ではなくなりました」

## 使うときの注意
- 数字は概算。iDeCoは受け取るときに課税されうることを、必ずセットで言う
- 「1億円」は「運用で増えれば」の話。元本の枠と混同させない
- 富裕層向けの話なので、一般の視聴者には「無理に満額を目指さなくていい」を添える（ネタ006）
