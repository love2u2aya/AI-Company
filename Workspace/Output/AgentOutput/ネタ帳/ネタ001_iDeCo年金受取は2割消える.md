# ネタ001｜iDeCoを65歳以降に年金で受け取ると、約2割が税金と保険料で消える

**登録日**: 2026-10-15
**発案**: 社長（TICKET-011の質疑から）
**状態**: 未使用（ストック）
**使えそうな場所**: iDeCo改正・後編の補足／セミナーの注意点／ショート動画1本

---

## 一言でいうと
公的年金を月13万円以上もらう人が、65歳以降にiDeCoを年金で受け取ると、受け取る額の約2割が税金と保険料で消える。退職所得控除に余裕があるなら、一時金の方が有利。

## 理屈（3行）
1. 公的年金とiDeCo年金は「公的年金等控除」を**1つの枠で共有**する（65歳以上は最低110万円）
2. 会社員だった人は公的年金だけで枠が埋まるので、iDeCo年金は**全額が上乗せ**になる
3. 上乗せ分には住民税・所得税と、**国保（75歳以降は後期高齢者医療）・介護保険料**がかかる

## 目安の数字（65歳以上・年金以外の収入なし・一人世帯）

| 公的年金＋iDeCo年金の合計（年） | 負担 |
|---|---|
| 110万円まで | 税金ゼロ |
| 約155万円まで | 住民税もほぼゼロ |
| 約200万円まで | 所得税はほぼゼロ。住民税は年3〜5万円ほど |
| 200万円超 | 上乗せ分に約15%（所得税5%＋住民税10%） |

※155万円を超えたあたりから住民税（約10%）がかかり始める。「200万円を超えた分だけ」ではない
※妻を扶養している夫は、住民税がかからない基準が上がる（合計所得で約100万円まで非課税の市区町村が多い）

## 具体例
年金 月14万円（年168万円）＋ iDeCo年金 月5万円（年60万円）＝ 年228万円

| | iDeCo年金なし | iDeCo年金あり |
|---|---|---|
| 所得税 | 0円 | ほぼ0〜数千円 |
| 住民税 | 約1万円 | 約6.5万円 |
| 保険料の増加 | ー | 年5万円前後 |

→ 上乗せは**年10万円前後＝iDeCo年金の約2割**

## 一時金との比較
- 退職所得控除の範囲内なら**税金ゼロ**
- 控除を超えても**超えた分の1/2に課税**（実質7〜8%程度）
- 退職所得は**国保・介護保険料の計算に入らない**

## 例外（必ず添える）
- **60〜64歳**（公的年金の前）や**繰り下げ中**は、年金形式でも年60〜110万円まではほぼ非課税
- ベストは組み合わせ：「**退職所得控除に収まる分は一時金、残りは公的年金の前に年金で**」
- 専業主婦の妻（基礎年金 年80万円前後）は、65歳以降でもiDeCo年金を年30万円まで雑所得ゼロ、年75万円くらいまで住民税もほぼゼロ

## 使うときの注意
- 数字は2026年10月時点の概算。住民税・保険料は市区町村で変わる
- 基礎控除は2026〜27年の改正で動くので、使う直前にFPが再確認
- 「年金受取は損」と断定しない。「公的年金が多い人の65歳以降は割高になりやすい」と言う
