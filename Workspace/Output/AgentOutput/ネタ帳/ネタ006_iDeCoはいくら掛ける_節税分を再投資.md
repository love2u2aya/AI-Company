# ネタ006｜iDeCoはいくら掛ける？ 戻った税金をもう一度投資に回すのが、枠が広がる本当の価値

**登録日**: 2026-10-15
**発案**: 社長
**状態**: 未使用（ストック）
**使えそうな場所**: iDeCo改正・前編の「いくら掛けるか」パート／後編の夫婦の分担（S18〜S19）／単独動画1本（「iDeCoはいくら掛ける？」）

---

## 一言でいうと
iDeCoで戻った税金を使ってしまうと、節税は1回きり（単利）で終わる。戻った分をiDeCoかNISAに上乗せすれば、節税分も一緒に増えていく（複利）。今までは月2.3万円の上限で上乗せできなかったが、12月からは6.2万円まで枠があるので、**最低でも「節税分を上乗せ」はやるべき**。

## 1. 「いくら掛けるか」を考える順番

| 受け取り方 | 考えること |
|---|---|
| **一時金**（退職所得） | 自分の年金額を調べる必要はない。iDeCo側で使える**退職所得控除**の範囲を見る |
| **年金形式**（雑所得） | 公的年金の見込み額が必要（ねんきん定期便・ねんきんネット）。公的年金と合わせて年200万円前後を超えると負担が増える（ネタ001） |

- 一時金でも、控除は「40万円×20年＋70万円×（年数−20年）」まで。しかも退職金と重なった期間は削られる（ネタ002・005）
- → 受け取るときに税金がかかる前提で、**控除を大きく超えるほどは掛けすぎない**
- ただし控除を超えても、課税されるのは超えた分の半分だけ。実質の税率は低いので、少し超える程度なら気にしすぎなくてよい

## 2. 一歩進んだ考え方：iDeCoは「税金の繰り延べ」。戻った分も投資する

- iDeCoは、今払うはずの税金を、受け取るときまで先送りしている
  - 受け取るときに控除の範囲に収まれば、先送りした税金はそのまま**消える**
- 先送りした分（年末調整で戻る所得税・翌年下がる住民税）を**使ってしまうと、効果は1回きり**
- 戻った分を投資に回せば、**投資額が増え、その分も増える**。当たり前だが、ここを意識している人は少ない

### 戻った分の置き場所

| 置き場所 | 評価 |
|---|---|
| iDeCoに上乗せ | ◎ 上乗せ分にもまた節税がつく |
| NISA | ◎ いつでも引き出せる。増えた分は非課税 |
| 特定口座（課税口座） | △ 増えた分に約20%かかる |

### 例：会社員（企業年金なし）、課税所得300万円くらい（所得税10%＋住民税10%）

| | 今まで | これから |
|---|---|---|
| 掛金 | 月2.3万円（上限） | 月2.3万円＋節税分 約0.5万円 ＝ **約2.8万円** |
| 1年の節税 | 約5.5万円 | 約6.7万円 |
| 節税分の行き先 | 上限で上乗せできない → 使ってしまいがち | iDeCoに上乗せできる |

- 節税分の約5.5万円を、毎年10年間、年3%で運用すると約63万円（使ってしまえば0円）
- **今まで2.3万円で上限だった人こそ、枠の拡大で「節税分の上乗せ」ができるようになる**。ここが今回の改正の地味だけど大きな価値

## 3. 6.2万円まで満額掛けられる人
- 月6.2万円を無理なく出せる人は、家計に余裕がある人
- 細かいことは考えすぎず、**将来のためにしっかり積み立てる**でよい
- 退職金が多くて控除を超えそうな人だけ、出口（一時金と年金の組み合わせ、ネタ001・005）を一度確認する

## 4. 夫婦の場合：妻のNISAの枠を使う

- 夫のiDeCoとNISAが埋まっている家庭でも、**専業主婦の妻のNISAは空いている**ことが多い
- 妻のNISAで運用すれば、夫婦で使える非課税の枠が増える（1人1,800万円）
- 妻にお金を移すときは**贈与**になる。次の3つを守る
  1. **年110万円まで**なら贈与税はかからない（暦年贈与の基礎控除）
  2. **贈与契約書**を作る（毎年）
  3. 口座は**妻が自分で管理**する（通帳・暗証番号・売買の判断）。夫が管理していると、相続のときに夫の財産（名義預金）とみなされやすい
- 専業主婦の妻のiDeCoは、掛けるときの節税がゼロ（後編S13）。手数料（毎月171円以上）もかかるので、**妻はNISAが先**
- パートで収入がある妻なら、iDeCoも少額で（後編S15〜S16）

## 言い回し案
「iDeCoで戻ってきた税金、何に使っていますか？ 使ってしまうと、節税は1回きりです。戻った分をもう一度iDeCoかNISAに入れると、その分も一緒に増えていきます。今までは月2.3万円が上限で、それができませんでした。12月からはできます。2.3万円でやってきた人は、最低でも節税分だけは上乗せしましょう」

## 使うときの注意
- 数字は概算（復興特別所得税を除く）。税率は課税所得で変わる
- 掛金の変更は原則年1回。ただし2026年12月〜2027年11月の最初の増額は回数に数えない
- 運用の利回りは仮定。「必ず増える」と言わない
- 贈与・名義預金の扱いは、使う直前にFPが再確認。相続税の「亡くなる前7年の贈与は加算」ルールにも触れるかは要検討
