# ネタ005｜退職所得控除の計算と、65歳で辞めても70歳までiDeCoを掛ける意味

**登録日**: 2026-10-15
**発案**: 社長
**状態**: 未使用（ストック）
**使えそうな場所**: iDeCo改正・後編のS05〜S07／セミナー／ショート動画2本（計算編・「間隔ルールはスルー」編）

---

## 1. 退職所得控除の計算（勤続45年でもそのまま計算してよい）

| 勤続年数 | 控除額 |
|---|---|
| 20年まで | 40万円×年数（最低80万円） |
| 20年超 | 800万円＋70万円×（年数−20年） |

- 上限はない。勤続45年でも同じ式で計算してよい
- 1年未満の端数は**切り上げ**（20年1か月なら21年）

| 勤続年数 | 控除額 |
|---|---|
| 20年 | 800万円 |
| 38年 | 2,060万円 |
| 40年 | 2,200万円 |
| 45年 | **2,550万円**（800万円＋70万円×25年） |

- iDeCoの一時金も同じ式。ただし年数は「**iDeCoに掛けた年数**」（運用だけの期間は入らない）

## 2. 65歳で退職しても、70歳までiDeCoを掛けると控除が増える

**例**：22歳入社・65歳退職（勤続43年）。iDeCoは55歳から。退職金を65歳で受け取り、iDeCo一時金は70歳で受け取る。

| | iDeCoを65歳でやめる | 70歳まで掛ける |
|---|---|---|
| iDeCoの年数 | 10年（全部が勤続と重なる） | 15年（重ならないのは65〜70歳の5年） |
| iDeCoの控除 | 400万円 | 600万円 |
| 重なった分の差し引き | −400万円 | −400万円 |
| **iDeCoで使える控除** | **0円** | **200万円**（＝40万円×5年） |

→ 退職後の5年は会社の勤続と重ならないので、**丸ごとiDeCoの控除として残る**

### 40万円か70万円かは「iDeCoの年数」で決まる
- 会社の勤続年数（43年）ではなく、iDeCoに掛けた年数で決まる
- iDeCoが合計20年以下なら、増える控除は **40万円×5年＝200万円**（50代から始めた人はほぼこちら）
- iDeCoが合計20年を超えるなら **70万円×5年＝350万円**（例：45歳から70歳まで掛けた人）

### 条件（必ず添える）
- 70歳まで掛けるには、**老齢基礎年金をまだ受け取っていないこと**。つまり国民年金は繰り下げる
- 退職金で控除を使い切る人の話。退職金が控除より少なければ、もともとiDeCo側も削られにくい（ネタ002）
- 退職後は収入が少ないので、掛金の所得控除（入口の節税）は小さい。メリットの中心は**出口の控除**
- 65歳からの加入は、それまでiDeCoを続けている人が対象（加入者か運用指図者だった人）

## 3. 「受け取りの間隔ルールが厳しくなった」はスルーでいい

SNSやYouTubeで「iDeCoと退職金の間隔ルールが5年から10年になった」という話がよく出る。**正しい話だが、対策として使える人はほぼいない。**

| 受け取る順番 | 差し引きを避けるのに必要な間隔 | 現実には |
|---|---|---|
| iDeCoが先→退職金が後 | 10年以上（2026年から。前は5年） | 60歳でiDeCo、**70歳以降に退職金**。会社員にはまずいない |
| 退職金が先→iDeCoが後 | 20年以上（前から同じ） | 60歳で退職金なら**80歳でiDeCo**。iDeCoは75歳までに受け取るので無理 |

- 影響を受けたのは「60歳でiDeCo、65歳で退職金」と計画していた人だけ。この人たちも、今からできることは少ない
- 気にするより、次の3つを考える方がずっと役に立つ
  1. 退職金で控除を使い切るかどうか（使い切らないなら、ほぼ問題なし）
  2. 退職後もiDeCoを掛けて、**重ならない期間**をつくる（上の2）
  3. 控除を超えそうなら、iDeCoの一部を**年金形式**で、公的年金の前（60〜64歳や繰り下げ中）に受け取る

### 言い回し案
「間隔のルールが厳しくなった、という話をよく見かけます。でも、これで得をできる人はほとんどいません。気にしなくて大丈夫です。それより、退職したあともiDeCoを続けて、会社と重ならない期間をつくる方が、ずっと効きます」

## 使うときの注意
- 計算は概算。端数の扱いなど細部は税理士・税務署で確認
- 自営業の小規模企業共済の一時金も退職所得。受け取り時期を動かせるので、間隔ルールが効く例外がありうる（会社員向けの話では触れない）
- 70歳まで掛ける条件（老齢基礎年金を受け取っていない等）は、使う直前にFPが再確認
