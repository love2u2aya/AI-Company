# ローカル引き継ぎ｜ElevenLabs「パパの声」で動画3本を作る

このファイルは、社長のPCで動くClaude Code（ローカルのセッション）への引き継ぎ書です。
ローカルのセッションには「このファイルを読んで、そのとおり進めて」と伝えればよい。

---

あなたはパパママ社の秘書兼Video_Producerです（リポジトリ: love2u2aya/AI-Company、ブランチ `claude/pensive-ride-p09ech`）。
社長の指示：「最新のナレーション原稿を、ElevenLabsのパパの声で読ませて、テロップを映像でつくって動画にして」。前編・後編・ネタ帳編の3本。
クラウド側ではElevenLabsにつながらないため、このPCで実行する。

## 1. 準備
1. `git fetch origin claude/pensive-ride-p09ech && git checkout claude/pensive-ride-p09ech && git pull`
2. 手順書 `Workspace/Output/AgentOutput/動画制作手順_ElevenLabsパパの声_20261015.md` を読む（詳しい手順はそこ）
3. `ffmpeg`・`ffprobe` があるか確認し、`pip install pillow`
4. 環境変数 `ELEVENLABS_API_KEY` があるか確認。なければ、ElevenLabsのサイト（API Keys）で作って環境変数に入れるよう社長に頼む。キーをチャットに貼ってもらわない

## 2. 「パパ」の声を探す（ElevenLabsで直接。HeyGenでは探さない）
- `python3 Organization/Video_Producer/Skills/produce_video_elevenlabs.py --list-voices`
- 名前に「パパ」を含む声が1つなら `--voice-name パパ`。なければ候補を社長に見せて選んでもらい `--voice-id` で指定

## 3. 作る
1. お試し：前編を `--limit 5` で作り、社長に聞いてもらって声・`--speed`・`--stability` を決める。設定を変えたら `Workspace/Output/FinalOutput/動画_…_work/audio/` を消して作り直す
2. 本番：3本を `Workspace/Output/FinalOutput` に書き出す（コマンドは手順書）
   - `ナレーション原稿_iDeCo改正前編_20261015.md`
   - `ナレーション原稿_iDeCo改正後編_20261015.md`
   - `ナレーション原稿_iDeCoネタ帳_8つのポイント_20261015.md`
3. ElevenLabsの文字数クレジットを約7,600字使う。始める前に残量を確認し、足りなければ社長に相談

## 4. 終わったら
- 3本を再生し、音声とテロップのずれ、読み間違い（数字・「iDeCo」・「専業主婦（主夫）」）を確認
- mp4・mp3はgitignore対象。`Workspace/Output/FinalOutput/動画_iDeCo改正_20261015.md` に尺・保存場所・声の名前とID・設定を記録
- TICKET-011（`Workspace/TicketManagement/Doing/`）の「Video_Producer（社長のローカルPC）」にチェック
- コミットして `claude/pensive-ride-p09ech` にpush（コミットメッセージにモデル名を入れない）
- 社長に保存場所と尺を報告。次はQCと社長承認②（非公開プレビュー）
