## 3. テロップ指示

> **基本方針**: スライドに既に文字情報が豊富に含まれているため、テロップはスライドに出ていない補足情報・視聴者の行動促しのみに絞る。スライドに重複する情報のテロップ化は不要。

| 項目 | 設定値 |

| 基本サイズ | 42px（本文） / 52px（強調） / 64px（パート見出し） |
| 基本色 | 白（#FFFFFF） |
| 強調色 | ゴールド（#FFD700） |

| 補足色 | スカイブルー（#4A9FD4） |
| 背景帯 | 黒80%（パート見出しテロップのみ） |
| 位置 | 画面下部（スライドの「📸 スクショしてください」アイコンと重ならないこと） |
| テロップとスライドの重複 | 禁止 |
