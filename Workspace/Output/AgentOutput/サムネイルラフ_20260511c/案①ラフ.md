# サムネイルラフ案 — iDeCoシリーズ第5弾・案①

**対応企画**: 案①「不安解消型：判断ツリーで不足額の正体を仕分ける」  
**採用タイトル**: 老後の不足額、3つの対策どれから始める？55歳が知るべき選び方  
**作成者**: Designer  
**作成日**: 2026-05-11  

---

## ラフA ―「自己選択」を前面に出した判断ツリー型

### キャッチコピー（15字以内）
```
どれから始める？
```
（8字。白抜き文字・黒縁 / フォントサイズ最大・画面中央上段に配置）

### サブコピー（20字以内）
```
3対策の正しい順番
```
（9字。黄色ベタ塗り帯の上に黒文字 / 右下エリアに配置）

| 要素 | カラーコード | 用途 |
|---|---|---|
| 背景 | #0D1B3E（ダークネイビー） | 全面ベース |

| 大見出し文字 | #FFFFFF（白）＋黒縁2px | キャッチコピー |
| サブコピー帯 | #F1C40F（黄色） | サブコピー背景帯 |

**詳細配置メモ**
- 左端（横幅の約25%）: 登場者の顔写真。右手の人差し指が判断ツリーを指向
- 画面上部中央〜右: キャッチコピー「どれから始める？」を最大サイズで配置
- 中央〜右下（横幅の約70%）: 判断ツリー。「不足額」赤ボックスを頂点に3本の緑矢印が分岐
- 積立iDeCoの矢印先端にオレンジの小バッジ（「加給年金あり」表記）
- 右下角: 黄色帯サブコピー「3対策の正しい順番」
- 左上角: 半透明白枠シリーズバッジ「第5弾 / 前作から続けて見ている方へ」

### 差別化ポイント
1. **自己関与感の視覚化**: 判断ツリーの「分岐」を画面内に再現することで、視聴者が「自分はどのルートか？」と無意識に照合する。一般的なiDeCo動画が「解説します」型なのに対し、本案は「あなたが選ぶ」型の構図。
2. **課題と解決の色分け**: 赤（問題）→緑（解決）という直感的な色対比により、「不安を解決してくれる動画」という印象をファーストビューで伝達。
3. **シリーズ連続視聴を促すバッジ**: 左上の「第5弾」バッジが既存視聴者の帰属意識を刺激し、シリーズ離脱を防ぐ。
4. **人物の指差しポーズ**: 登場者の視線と指の方向がツリーに向かうことで、視聴者の視線誘導が自然に「課題→分岐→解決策」の順に流れる。

**詳細配置メモ**
- 左1/3: 登場者顔写真（胸上）、驚き顔＋右手人差し指を右に向ける
- 右2/3上段: 赤文字キャッチ「不足額、どこから埋める」
- 右2/3中段: 緑丸バッジ①②③と対策名（就労継続・繰り下げ・積立iDeCo）を横並び

### 差別化ポイント
1. **数字・ラベル最小化でスキャン速度最大化**: スマートフォンのサムネイル表示（縦横100px程度）でも①②③のバッジと赤文字が瞬時に視認できるシンプルレイアウト。
2. **「55歳」という年齢明記**: ターゲット読者が自分事として反応しやすい年齢ラベルを下部帯に据え、関係性の薄い視聴者を自然に離脱させつつコア層のクリック率を向上。
3. **ラフAとの使い分け**: ラフAが「ツリー図の複雑さ＝専門性の演出」、ラフBが「シンプルな数字＝取っつきやすさ」。ABテストで2案を比較検証できる。

## 推奨・補足メモ（Designerより）

- **推奨案**: ラフA。Criticコメントの「自己関与感」を判断ツリーの構図で最も忠実に体現している。
- **ラフBの出番**: 初稿アップ後にCTRが想定を下回る場合の差し替え候補として保持。
- **フォント指定**: 見出し系は「UD黒丸ゴシック」もしくは「Noto Sans JP Black」推奨（太字・可読性重視）。
- **画像サイズ**: YouTube標準サムネイル 1280×720px（16:9）。重要要素はセーフゾーン内（左右各64px、上下各36px）に収める。
- **人物写真**: 既存の登場者写真素材を使用。背景除去済みPNGをネイビー背景に合成。
