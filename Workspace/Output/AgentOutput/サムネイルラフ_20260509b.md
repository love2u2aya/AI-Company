## 1. サムネイルコンセプト

### 訴求の核心
「増額すれば得するはず」という常識を真正面から裏切る**逆張りショック**。
「知らずに損した」という後悔感情を視覚的に先取りさせ、クリックを誘導する。

### 感情訴求の方針
- **一次感情**：「ギョッとする」「まさか自分が？」という軽い恐怖と違和感
- **二次感情**：「今すぐ確認しないと危ない」という行動衝動
- 「騙された」系ではなく「自分だけ知らなかった」系のトーンに寄せる
  → 55歳前後の男性はプライドが高く、「被害者感」より「情報弱者を回避したい」動機が強い

### カラーパレット
| 役割 | 色 | 意図 |
|---|---|---|
| 背景 | 黒（#0A0A0A） | 警告・緊張感・高級感 |
| メインアクセント | 深紅（#C0192A） | 「損」「危険」の信号色。金融系でも威圧感が出ない深みのある赤 |
| メインテキスト | 黄色（#FFD700） | 圧倒的な視認性。黒背景との組み合わせで最大コントラスト |
| サブテキスト | 白（#FFFFFF） | 読みやすさ確保 |
| 強調数字 | 白抜き太字 or 黄色 | 金額を際立たせる |

### 構図方針
- **縦書き × 横割り構成**（横1280×縦720px想定）
- 上部1/3：「2026年改正」注意バッジ（深紅の警告ラベル風）
- 中央1/2：メインテキスト（最大フォントで2行）
- 下部1/5：サブテキスト（金額・補足）
- テキスト主体・顔出しなし・イラスト不使用（チャンネル方針に準拠）
- 数字（「最大300万円」）は他テキストの1.5〜2倍サイズで圧倒的に目立たせる

## 3. 文字テロップ案

### メインコピー（最大サイズ・黄色）
```
iDeCo増額した人
ほど損する
```
- フォントサイズ感：他要素の2〜2.5倍（サムネ上で最も目に飛び込む要素）
- フォント：極太ゴシック（Noto Sans JP Black / UD デジタル教科書体 等）
- 字間：やや詰め（圧迫感で緊張を演出）

### 警告バッジ（上部・深紅背景＋白文字）
```
2026年改正　落とし穴
```
- フォントサイズ感：サムネ高さの約8〜10%
- 背景ラベル形式（スタンプ風 or タグ風）
- 「！」マークやビックリアイコンは使わない（扇情的すぎる印象を避ける）

### サブコピー（下部・白文字）
```
退職金と同時受取で　最大300万円 消えた事例
```
- 「最大300万円」だけワンサイズ大きく・太く
- 「消えた事例」は実話感を出すためにやや小さめで補足的なトーン
- フォントサイズ感：メインの50〜60%

### テキスト全体のバランスイメージ
```
┌─────────────────────────────────┐
│  【深紅バッジ】2026年改正 落とし穴       │
│                                   │
│  iDeCo増額した人                   │（黄・極大）
│  ほど損する                        │（黄・極大）
│                                   │
│  退職金と同時受取で 最大300万円 消えた事例 │（白・中）
└─────────────────────────────────┘
```

## 4. デザイン意図の説明

### なぜ黒×深紅×黄色の配色か
55歳前後の男性は、金融系コンテンツに慣れており「青×白（信頼感）」や「オレンジ（明るい節税）」系サムネを日常的に目にしている。そこに**黒背景×深紅アクセント×黄テキスト**という、より強い緊張色を配置することで、フィードの中での「色の異常値」として目に引っかかる。

深紅は「赤」ほど安っぽくなく、「黒」に溶け込まず、「危険・警告」の信号としての文化的記号性を持つ。新聞の号外・銀行の警告書類・金融庁のアラートに使われる配色に近く、ターゲット層の「重大なことが書いてある感」センサーに引っかかりやすい。

### なぜ「ほど損する」という逆接フレーズをメインに据えるか
「増額した人ほど損する」という構造は、行動経済学でいう**現状維持バイアスへの衝撃**として機能する。増額手続きを終えた人、あるいは増額を検討中の人が「自分がやったこと（やろうとしていること）が実は逆効果かもしれない」という認知的不協和を起こし、クリックせずにいられない状態になる。

サムネイルの文言を「iDeCo 落とし穴」や「iDeCo 損する仕組み」にしないのは、主語を「増額した人」に限定することで「自分に刺さる話かもしれない」という当事者感を高めるためである。

### なぜ「顔出しなし・テキスト主体」で構図を作るか
顔出しなしのチャンネルで顔写真や仰天表情の人物イラストを使うと、チャンネルトーンとの乖離が生じ、信頼感が下がる。また55歳前後の男性視聴者は「ネタバレ的な衝撃顔」よりも「内容が具体的そうな数字と文字」を信頼する傾向がある。

テキスト主体にすることで「サムネを見るだけで内容の概要がわかる → 続きが気になる」という情報欲求を適切にコントロールできる。数字（「300万円」）は情報の具体性の証明として機能し、「なんとなく怖い」ではなく「300万円という根拠があるから信憑性が高い」という判断を視聴者に与える。

### バッジ「2026年改正 落とし穴」の役割
批評レポートが指摘した「タイムリー性が唯一無二」という強みをサムネイルにも反映するための要素。「2026年改正」という時制を画面上部に置くことで、これがタイムリーな最新情報であることを瞬時に伝える。フィードで見た瞬間に「最近のニュースと関係あるやつだ」と分類してもらえる。
