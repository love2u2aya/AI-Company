## 1. サムネイルコンセプト

### 訴求の核

「月22万円」という定期便の数字が、口座に振り込まれる時点では「月18万円」になる——この事実を「知らなかった」と感じる瞬間を1枚で作る。数字を見た瞬間に「自分の定期便と照らし合わせる」という自己投影が発動し、クリックが起きる設計。

---

### 感情訴求の設計

**狙う感情：「気づかされた」という軽い衝撃**

- 「知らなかった」「自分も同じことをしていた」というマイルドな後悔と、「今すぐ確かめたい」という前向きな行動衝動を同時に起こす
- 「怖い・損する・絶望」ではなく「知らなかったことが恥ずかしい／もったいない」という45〜60歳向けの自己改善欲求に訴える
- 第3弾（VS対比・驚き構造）と同系統の「数字の落差」訴求を継続しつつ、今回は取り消し線→矢印という「修正・補正」の視覚言語を加える

---

### 構図設計

**レイアウトコンセプト：「取り消し線で消された22万円と、矢印で示された18万円」**

```
┌──────────────────────────────────────────────────────┐  ← Y=0
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓               │
│▓  年金 手取りの落とし穴（白・36px）  ▓               │  ← 深紅バッジ（左ブリード）Y=40〜104px
│▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓▓               │
│                                                      │
│  月22万円（黄・120px・取り消し線つき）                 │  ← Y=130px〜
│         ↓（深紅矢印・垂直）                          │  ← Y=310px〜340px
│  月18万円（白・110px・クリーン・強調）                 │  ← Y=355px〜
│                                                      │
│  ─────────────────────────（深紅ライン・3px）──────── │  ← Y=540px
│                                                      │
│  定期便の数字、そのまま使っていませんか（白・38px）      │  ← Y=600px
└──────────────────────────────────────────────────────┘  ← Y=720px
```

**構図の意図：**
- 「月22万円」に深紅の取り消し線を引くことで「それは間違い」という視覚的ショックを与える
- 下向きの矢印（深紅）が「修正・補正」の流れを示し、「月18万円」へと視線を誘導する
- 上段の「取り消された数字（黄）」と下段の「正しい数字（白）」の色の違いが「誤り vs 真実」を自然に伝える
- サブコピーが「あなたはどちらですか？」という自己点検への呼びかけとして機能する

### 「月22万円」の取り消し線の視覚設計

- 取り消し線：深紅（`#B01020`）、太さ14px（120px文字に対して視認可能な最低太さ）
- 取り消し線角度：水平（0度）。斜め線より「明確に否定された」印象が強い

- 「月」の文字の上端から「円」の文字の右端までを貫通させる（文字列全体を横断）

## 3. 文字テロップ確定版

### バッジ（上部・深紅背景）

```
年金 手取りの落とし穴
```

- 配置：左上（左端ブリード）、Y=40px（上端）、高さ64px固定
- 背景色：`#B01020`（矩形・ブリードラベル、角丸なし）。X=0〜X=560px（min-width）
- 文字色：`#FFFFFF`
- フォント：Noto Sans JP Black、36px、字間-1px
- 垂直センタリング：バッジ高さ64px内でテキストを上下中央揃え
- **確定理由**：「年金」でテーマを直接提示。「手取りの落とし穴」は「知らなかった」感を刺激する感情ワード。前回（「老後の必要額　衝撃の差」）・前々回（「退職金受取直前　警告」）と同じ「テーマ+感情ワード」の2語構成でシリーズ文法を4本通じて維持する。
- **バッジmin-width算出根拠**：「年金 手取りの落とし穴」10文字（スペース含む）。Noto Sans JP Black 36pxでの1文字あたりの概算横幅は約34〜38px。10文字×36px幅+左padding40px+右padding36px≒476〜516px。560pxをmin-widthに指定（前回520pxより40px拡張し、バッジの存在感を維持）。

### 各弾の「数字の見せ方」の進化とその意図

**第1弾：1つの大きな数字**
→ 「これだけ知ってほしい」という情報の圧縮。シリーズ開始の掴み。

**第2弾：メイン数字＋サブ数字の対比**
→ 主従関係のある2つの数字で「本命と前提」を伝える構造へ進化。

**第3弾：2数字・水平VS対比（区切り線）**
→ 「共働き vs 専業主婦」という明確な2択対比。水平の区切り線がVSを体現。

**第4弾：2数字・垂直修正構造（取り消し線＋矢印）**
→ 「誤り（定期便の数字）→正しい（手取り）」という時系列の補正を垂直方向で体現。水平VS対比（第3弾）から垂直修正構造（第4弾）への変化は、シリーズとして「比較から補正へ」というコンテンツの深化を視覚的に反映している。

**一貫して変えない要素**：黒背景・深紅バッジ・黄色数字という三要素。この組み合わせが「パパママ社の金融警告シリーズ」として視聴者の脳内にブランドイメージとして蓄積される。

---

### 今回の意図的差分とその根拠

**差分①：「月22万円」の文字色を黄色に、「月18万円」を白に分けた**
- 根拠：黄色＝「定期便に書かれた"見かけの数字"＝危険なもの」、白＝「手取りとして口座に入る"本当の数字"＝正確なもの」という色の意味付けを今回から導入。シリーズの「黄色＝数字」文法を維持しつつ、白を「補正後の正しい答え」として位置づけることで新しい色の役割を加える。

**差分②：垂直方向の矢印を新たに使用**
- 根拠：第3弾の水平区切り線が「VS（対立・比較）」を表すのに対し、垂直矢印は「修正の方向（上から下へ）」を表す。今回の動画テーマ「補正・精度向上」を一致させた必然的な変更。

**差分③：取り消し線という新たな視覚要素**
- 根拠：「定期便の数字が間違い」という主張を最も直感的に伝える視覚言語が取り消し線。文字で説明せずとも「×」という否定の意味を瞬時に伝える。金融コンテンツのサムネイルで取り消し線は稀であり、差別化にもなる。
