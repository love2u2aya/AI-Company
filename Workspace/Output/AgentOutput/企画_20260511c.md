## 企画案①「不安解消型：判断ツリーで不足額の正体を仕分ける」

### タイトル案（A/Bテスト用3パターン）

- A：`iDeCo 不足額が出た人が次にやること【55歳からの3対策・優先順位つき】`（30字）
- B：`老後の不足額、3つの対策どれから始める？55歳が知るべき選び方`（31字）
- C：`不足額が出た。でも何から手を打つか分からない人への設計講座`（30字）

### 結論（0:00に言う一言）

「不足額が出た瞬間、多くの人が積立を増やそうとします。でも正しい順番は逆です。今日は"課題額の大きさ"によって対策の組み合わせがまったく変わる、その判断ツリーをお伝えします。」

### なぜ今この動画を出すのか

第4弾で視聴者の手元に「本当の不足額」が出た。数字が出た直後が最も行動意欲の高い瞬間であり、同時に「何から手を付けるか」で判断を誤りやすいタイミング。第4弾の計算シートの数字をそのままこの動画の判断ツリーに入力できる設計にすることで、「計算した→次の動画で設計した」という連続体験を作り、シリーズ離脱を防ぐ。

### 各パートの「小さな驚き」

1. **「積立を増やすのは最後の手段」という驚き**（イントロ〜第1パート）
   大半の視聴者は「不足額 → iDeCoを増やす」と直感的に考えている。しかし就労継続1年延長で得られる効果はiDeCo積立増額の数倍に相当することが多い。「節税効果は確実だが規模が小さい」という位置づけを数値で示すことで、優先順位の逆転が"驚き"になる。

2. **「加給年金は配偶者がいるだけで年約39万円が自動加算される」という驚き**（第2パート）
   繰り下げを検討する前に、加給年金の存在を知らないまま繰り下げると年約39万円を丸ごと失う可能性がある。「繰り下げが得かどうか、実は配偶者の有無で結論が変わる」という事実は多くの人が知らない。

3. **「課題額が100万円未満・100〜300万円・300万円超で対策の組み合わせが別ルートになる」という驚き**（第3パート）
   判断ツリーを3段階に分けて見せると、視聴者が自分のルートを再確認する体験が生まれる。「課題額が小さいほど繰り下げ一択で解決できる」という意外なシンプルさが驚きになる。

4. **「5年間の目標は"解決"ではなく"選択肢を増やす"こと」という驚き**（まとめパート）
   不安が「解決不能な問題」から「設計可能な問題」に変わるリフレーミング。

### サムネイルコンセプト

- **構図**: 左側に「不足額」と書かれた赤いメモ用紙、右側に3つの矢印（就労継続・繰り下げ・積立）が分岐するシンプルな判断ツリー図
- **文字**: 中央大見出し「どれから始める？」（白抜き・黒縁）、右下に「3対策の正しい順番」（黄色）
- **顔**: 画面左端に登場者が少し驚いた表情で判断ツリーを指差すポーズ
- **色**: 背景ネイビー。赤（課題額）・緑（解決策）の2色。加給年金の箇所だけオレンジのバッジ
- **その他**: 「第4弾から続けて見ている人へ」という小さなシリーズバッジを左上に添える

### 想定タイムスタンプ

| 時間 | パート | 内容 |
|------|--------|------|
| 0:00〜0:30 | イントロ・結論 | 「積立を増やすのは最後」宣言。この動画で分かること3点提示 |
| 0:30〜2:00 | 第4弾との橋渡し | 計算シートの数字を判断ツリーに入力する方法を画面で実演 |
| 2:00〜4:30 | 就労継続の効果 | 1年延長で何が変わるか。ダウンサイドシナリオも提示 |
| 4:30〜7:00 | 繰り下げ受給の条件確認 | 加給年金の盲点。橋渡し問題。条件が揃わない場合の代替案 |
| 7:00〜9:00 | 積立増額のポジション | 節税効果は「今年から確実に得られる唯一のリターン」 |
| 9:00〜11:00 | 判断ツリー実演 | 課題額の規模別（小・中・大）に対策の組み合わせを分岐 |
| 11:00〜12:30 | まとめ・次回予告 | 「選択肢を増やす5年間」のリフレーミング |

## 企画案②「比較選択型：3対策の数字を並べて自分で選ばせる」

### タイトル案（A/Bテスト用3パターン）

- A：`繰り下げ vs 就労継続 vs 積立増額、55歳の不足額を埋めるのはどれか`（34字）
- B：`老後2000万の不足を3対策で比べた結果、1位は意外な方法だった`（32字）
- C：`iDeCo増額より先にやること｜55歳が比較すべき3つの選択肢【数字で検証】`（35字）

### 結論（0:00に言う一言）

「同じ不足額200万円でも、繰り下げ受給と就労継続1年延長と毎月の積立増額では、手元に残るお金がまったく違います。今日はその3つを同じ土俵で数字比較して、あなたに合った組み合わせを選んでいただきます。」

### なぜ今この動画を出すのか

第4弾で「課題額」という共通の出発点が視聴者全員に揃った。比較コンテンツは検索流入・サムネクリック率が高い形式であり、新規視聴者がシリーズ5弾から入っても価値を感じられる設計にする。

### 各パートの「小さな驚き」

1. **「繰り下げ受給の損益分岐点は84歳だが、配偶者がいると計算が根本から変わる」**（第2パート）
   加給年金（年約39万円）は配偶者が65歳になるまで受給できる。繰り下げ中はこれが止まる。「夫婦で試算すると繰り下げが得になる年齢が90歳以降にズレる場合がある」。

2. **「就労継続の効果は積立増額の3〜5倍が一般的だが、最も不確かな対策でもある」**（第1パート）
   「効果最大・確実性最低」という特性を正直に提示することで、「自分のリスク許容度で選ぶ」という設計思考を促す。

3. **「65〜70歳の生活費の原資が決まっていない状態での繰り下げ検討は机上の空論」**（第2パート）
   橋渡し問題の盲点。65〜70歳の5年間の生活費（月25万円 × 60ヶ月 = 1,500万円）をどう調達するかが先決。

### サムネイルコンセプト

- **構図**: 3つのボックスを横並びに配置（就労継続・繰り下げ・積立増額）。それぞれの下に仮の金額を表示し、1位に金色の「No.1」バッジ
- **文字**: 上部に「3対策、本当に効くのはどれ？」（白・大）、下部に「同じ不足額で比べてみた」（黄色・小）
- **顔**: 登場者が3つのボックスのうちの1つを指差しながら驚き顔
- **色**: 背景は濃いグレー。1位のボックスだけ金色の枠線。2位・3位は白枠

### 想定タイムスタンプ

| 時間 | パート | 内容 |
|------|--------|------|
| 0:00〜0:40 | イントロ・比較宣言 | 「3対策を同じ不足額200万円で比較する」と宣言 |
| 0:40〜2:00 | 比較の前提条件設定 | 55歳・課題額200万円・配偶者あり・健康状態良好という標準ケースを設定 |
| 2:00〜5:00 | 対策①：就労継続の試算 | 1年延長の効果を4項目で金額化。ダウンサイドシナリオも並記 |
| 5:00〜8:00 | 対策②：繰り下げ受給の試算 | 加給年金の盲点を先に説明。橋渡し問題の原資計算 |
| 8:00〜10:00 | 対策③：積立増額の試算 | 節税効果を「今年から確実なリターン」として位置づけ |
| 10:00〜12:00 | 比較まとめ・条件別ランキング | 課題額の規模別と配偶者の有無でランキングが変わることを表で整理 |
| 12:00〜13:30 | 視聴者への問いかけ・次回予告 | 「あなたはどのルートか」を計算シートで確認するよう促す |

## 企画案③「行動促進型：今月から動ける具体的アクション設計」

### タイトル案（A/Bテスト用3パターン）

- A：`55歳から5年、老後の課題額を減らすために今月やること【iDeCo設計実践】`（35字）
- B：`不足額が出た55歳がまず動くべき3ステップ｜iDeCoより先にやることがある`（35字）
- C：`老後の準備、5年前に始めた人と始めなかった人の差【55歳・行動設計編】`（34字）

### 結論（0:00に言う一言）

「今日この動画を見終わったら、この3つだけやってください。順番に意味があります。1つ目は就労の見通しを確認すること、2つ目は加給年金の受給資格をチェックすること、3つ目だけがiDeCoの設定変更です。」

### なぜ今この動画を出すのか

第4弾で不足額が出た視聴者は「行動したい」というモチベーションが最も高い状態にある。「今月・今年・5年間」という時間軸でアクションを具体的に分解することで、「視聴直後に1つ動ける」体験を提供する。行動コンテンツはコメント欄での報告・拡散が起きやすい。

### 各パートの「小さな驚き」

1. **「就労継続は"継続できるかの確認"を今すぐすべき理由」**（第1パート）
   55歳は会社の再雇用制度・役職定年・退職金の計算基準を把握できる最後のタイミングであることが多い。「5年前に確認した人としなかった人では、選択肢の数がまったく違う」。

2. **「加給年金の受給資格確認は"繰り下げを決める前"に必ずやること」**（第2パート）
   配偶者との年齢差が5歳以上ある場合、繰り下げによる損失が増額効果を上回るケースがある。「加給年金チェックリスト」を3項目に絞って提示。

3. **「iDeCoの節税効果は"就労継続中にしか得られない"という時間制限」**（第3パート）
   退職・廃業後はiDeCoへの新規積立ができなくなる。「就労継続の5年間は節税メリットを最大化できる最後のウィンドウ」。

4. **「ダウンサイドシナリオを先に設計すると就労継続の意思決定が楽になる」**（第1パート補足）
   ネガティブシナリオを先に設計することが行動促進につながるという逆説。

### サムネイルコンセプト

- **構図**: 縦3段のリスト形式「今月やること」「今年やること」「5年間やること」が箇条書きで並ぶ。チェックボックスを模したデザインで1段目だけにチェックが入っている
- **文字**: 最上部に「不足額が出たらすぐやること」（白・大）、左下に「55歳の行動設計」（黄色・小）
- **顔**: 登場者がリストを持って「これだけ！」という表情で指差し
- **色**: 背景は深緑。チェックの入ったボックスはオレンジ。文字は白と黄色

### 想定タイムスタンプ

| 時間 | パート | 内容 |
|------|--------|------|
| 0:00〜0:30 | 結論提示 | 今日やること3つを先に列挙。「順番に意味がある」と強調 |
| 0:30〜1:30 | 第4弾との連動確認 | 計算シートの「課題額」の数字を手元に用意するよう促す |
| 1:30〜4:30 | アクション①：就労継続の見通し確認 | 会社の再雇用制度・役職定年・退職金を今すぐ確認すべき理由 |
| 4:30〜7:30 | アクション②：加給年金チェックリスト | 加給年金の仕組みを3分で説明。今すぐ確認できる3項目 |
| 7:30〜9:30 | アクション③：iDeCo積立額の見直し | 掛金上限への到達確認。来月分から変更できる手続きフロー |
| 9:30〜11:00 | 課題額別の優先度調整 | 小・中・大で3アクションの比重が変わることを整理 |
| 11:00〜12:30 | 行動宣言・コメント促進 | 「今日実行したことをコメントに書いてください」と明示的に促す |
