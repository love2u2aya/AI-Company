### 修正条件
1. **タイトルはB案を短くして採用**：
   `iDeCo、55歳で始めると63歳まで受け取れない｜12月改正と50代の落とし穴`（36字）
2. **「変更届を出さないと掛金は上がらない」はFPが一次資料で確認すること**（競合の解説記事が根拠。間違っていると視聴者に実害が出る）
3. 節税率の表には「復興特別所得税を含めると約15.1%」などの注記を画面下に入れる

## 後編｜出口と夫婦編

| 軸 | 点数 | コメント |
|---|---|---|
| 新鮮さ | 18/20 | 人気動画はほぼ個人目線。「夫婦の分担」「妻の掛金は夫の控除にならない」は明確に差別化できる |
| ターゲット刺さり度 | 18/20 | 退職金がある会社員と専業主婦の組み合わせは、50代のメイン視聴者層にそのまま当てはまる |
| タイトル訴求力 | 17/20 | **A案が最強**（「節税ゼロ？」の疑問形に意外性がある）。B案は具体的だが平板 |
| 構成の実現可能性 | 15/20 | **14分に情報が多すぎる**。退職所得控除・10年ルール・19年ルール・年金形式・2ケースが並び、途中で離脱されやすい |
| タイムリー性 | 16/20 | 10年ルールが2026年から始まった点と、前編の続きであることで出す理由は立つ |
| **合計** | **84/100** | |

### 修正条件
1. **構成を軽くする**：
   - 19年ルールは画面の注記に回し、口頭では10年ルールだけ説明する
   - 一時所得との比較は1分以内（表1枚）に収める
   - 夫婦ケース（8:30〜12:00）を3.5分→4.5分に広げる。ここが差別化の主役
2. **「専業主婦は節税ゼロ」の例外を冒頭近くで言う**：パート収入があり税金を払っている人は対象外。言わないと「うちは違う」とコメント欄が荒れる
3. 「専業主婦（主夫）」と概要欄に明記し、性別を決めつけない配慮を入れる
4. 夫のおすすめ案（繰り下げ中にiDeCoを年金で受け取る）は「一例」と明示し、断定しない（FPブリーフ§9のリスク管理）
