# 前編｜入口と改正編

### タイトル案（3パターン）
- A：`12月からiDeCoが変わる｜50代が知るべき「すごい点」と「2つの落とし穴」`
- B：`iDeCo、会社員は月6.2万円まで。でも55歳で始めると63歳まで受け取れない【2026年12月改正】`
- C：`NISAと同じ「非課税」は誤解｜iDeCoの基礎と12月改正を50代向けに解説`

### 結論（0:00に言う一言）
「iDeCoは、"確実な節税"と"上がり下がりする運用"がセットになった乗り物です。12月から会社員は月6.2万円まで入れられ、70歳まで続けられるようになります。ただ、50代には知っておくべき落とし穴が2つあります。」

### 構成（タイムスタンプ）

| 時間 | パート | 内容 | 画面のイメージ |
|---|---|---|---|
| 0:00〜0:30 | 結論 | 上の一言＋この動画で分かること3点 | 3点の箇条書き |
| 0:30〜2:30 | NISAとの最大の違い | 掛金が全額所得控除。課税所得195万円以下なら約15%、高いほど最大約55%が戻る。「すごい」 | 課税所得別の節税率の表 |
| 2:30〜4:00 | でも節税は"単利" | 節税はその年に1回戻るだけで増えない。運用は複利だが上がり下がりする（ジェットコースター） | 左：一定の棒グラフ（節税）／右：波打つ線（運用） |
| 4:00〜5:30 | 「NISAと同じ非課税」は誤解 | 入口と運用中は非課税、**出口で課税**（ただし控除が大きい）。運用中の特別法人税は「凍結中」なだけ（2029年3月まで） | 入口→運用→出口の3段階図 |
| 5:30〜7:30 | 落とし穴①：60歳まで引き出せない…だけじゃない | 50代なら60歳ロックは短い。でも**60歳時点で加入10年未満だと受け取り開始が遅れる**。55歳開始なら63歳から | 加入期間→受け取り開始年齢の表 |
| 7:30〜9:30 | 12月改正①：上限アップ | 会社員（企業年金なし）2.3万→**6.2万**、自営業6.8万→7.5万、**専業主婦は2.3万のまま**。掛金を上げるには**自分で変更届**が必要 | 区分別の改正前後表 |
| 9:30〜11:00 | 12月改正②：70歳まで | 掛金を入れられるのは**70歳まで**、運用だけ続けて置いておけるのは**75歳まで**。受け取り始めたら掛けられない | 年齢の帯グラフ（60/70/75） |
| 11:00〜12:30 | 50代の使い方：落とし穴②とバランス | 「そんなにお金ある？」→ 預金をiDeCoに移す考え方。**定期預金を選んでも節税は満額**。ただし生活防衛資金は入れない（落とし穴②） | お財布3つの図（預金／NISA／iDeCo） |
| 12:30〜13:00 | まとめ・後編予告 | 「入れるときはお得。でも出口で税金がかかる。しかも夫婦だと話が変わる」 | 後編サムネを小さく |

### 小さな驚き（各パートに1つ）
1. 節税率は最大約55%。でもそれは「1回きり」で増えない
2. 「非課税」なのは入口と運用中だけ。出口では課税される
3. **55歳で始めると、受け取れるのは63歳から**
4. **専業主婦（主夫）の上限は据え置き**（後編への伏線）
5. **iDeCo内で定期預金を選んでも、節税はまるごと受けられる**

### やってはいけないこと（締め用）
- 生活防衛資金までiDeCoに入れる（60歳以降まで引き出せない）
- 改正後に**変更届を出さずに放置**する（掛金は自動では上がらない）

### サムネイルコンセプト
- 大見出し「12月からiDeCoが変わる」、サブ「50代の落とし穴2つ」
- 「6.2万円」を大きな数字で。右下に「55歳→63歳」の小さな警告バッジ
- 色：ネイビー背景、数字は黄色、落とし穴は赤

# 後編｜出口と夫婦編

### タイトル案（3パターン）
- A：`専業主婦のiDeCoは節税ゼロ？退職金がある夫と妻の正しい分け方【iDeCo改正・後編】`
- B：`iDeCoの税金は受け取り方で変わる｜退職金2,000万円の夫と専業主婦の妻で試算`
- C：`退職金で控除が埋まる人はiDeCoをどう受け取る？一時金・年金・夫婦の分担を解説`

### 結論（0:00に言う一言）
「出口で使える控除は2つあります。**退職金ですでに埋まった控除ではなく、空いている控除を使う**。そして専業主婦の妻は、iDeCoよりNISAが基本です。今日は退職金がある夫と専業主婦の妻のケースで、具体的に見ていきます。」

### 構成（タイムスタンプ）

| 時間 | パート | 内容 | 画面のイメージ |
|---|---|---|---|
| 0:00〜0:30 | 結論 | 上の一言 | 夫婦のイラスト＋「空いている控除を使う」 |
| 0:30〜1:00 | 前編のおさらい | 入口はお得、出口で課税 | 前編の3段階図を再掲 |
| 1:00〜3:00 | 出口の税金は3種類 | 一時金＝退職所得、年金＝雑所得。似ている「一時所得」との違い（どちらも1/2が出てくるので混同注意） | 退職所得と一時所得の比較表 |
| 3:00〜4:30 | 退職所得は税率が上がりにくい | 控除は勤続年数（iDeCoは掛けた年数）で増える。（収入−控除）×1/2を**分離課税** | 控除額の計算式と早見表 |
| 4:30〜6:00 | 2026年からの10年ルール | iDeCo先→退職金後は「9年以内」なら控除が重なって減る。退職金先→iDeCo後は「19年以内」 | 時間軸の図（60歳・65歳・70歳） |
| 6:00〜7:00 | 70歳まで掛けると控除が伸びる | 60歳以降の期間は会社の勤続と重ならないので、削られにくい | 期間の重なりの図 |
| 7:00〜8:30 | 年金形式で受け取るのが向く人 | 退職金で控除を使い切る人／公的年金をまだ受け取っていない期間がある人。向かない人：公的年金が多い、国保・介護保険料を上げたくない、退職金がない自営業 | 向く人・向かない人の2列 |
| 8:30〜10:30 | ケース①：夫 | 55歳・会社員・退職金2,000万円（控除約2,060万円でほぼ埋まる）。節税は年約8万→約22万円。受け取り方A〜Dを比較。**おすすめは「公的年金を70歳まで繰り下げ、その間iDeCoを年金で受け取る」** | 4択の比較表 |
| 10:30〜12:00 | ケース②：専業主婦の妻 | 収入がないので**節税ゼロ**。**妻の掛金を夫の所得から控除することはできない**。運用益非課税だけならNISAで足りる → NISA優先。例外：パート収入がある場合 | 「節税0円」の大きな数字 |
| 12:00〜13:00 | 夫婦の分担 | 夫のiDeCo＝節税枠／妻のNISA＝自由に使えるお金とリスクを取る枠／預金＝生活防衛資金 | 3つの箱の分担表 |
| 13:00〜14:00 | まとめ・次の動画へ | 第5弾（繰り下げ）へのリンク | 終了画面 |

### 小さな驚き（各パートに1つ）
1. 退職所得と一時所得はどちらも「1/2」。でも控除の大きさと課税方法が全然違う
2. 60歳でiDeCo、65歳で退職金、という従来のやり方は**2026年から効きにくくなった**
3. **公的年金の繰り下げ中は、年110万円の控除がまるごと空いている**
4. **妻の掛金は、夫の節税には使えない**
5. 夫婦なら「夫はiDeCo、妻はNISA」が基本形

### やってはいけないこと（締め用）
- 退職金とiDeCo一時金の受け取り時期を、何も考えずに近づける
- 「妻名義のiDeCoでも節税になる」と思い込んで始める

### サムネイルコンセプト
- 夫婦の2人のイラスト。妻の側に「節税0円？」、夫の側に「控除が埋まる」
- 大見出し「iDeCo 夫婦の正しい分け方」
- 色：前編と同じトーン（シリーズ感）。「後編」バッジを左上に
