## 毎サイクルの流れ

```
【Day 1】
FP → 深掘りブリーフ（テーマ設定）
Planner → 企画3案（FPブリーフ参照・YouTube調査込み）
Critic → 5軸審査（PASS/CONDITIONAL/REVISE/REJECT）
Designer → サムネイルラフ（Critic PASS後）
社長 → 承認①（GO/NG）

【Day 2】
Creator → ナレーション原稿
Designer → サムネイル本番仕様
Editor → 編集指示書

【Day 3】
FP → 台本ファクトチェック（任意・重要テーマの場合）
社長 → 承認②
SNS_Manager → 投稿準備シート・スケジュール設定
```

## シリーズ管理

複数の動画を連続して制作する場合、シリーズとして設計する。

| シリーズ名 | 本数 | 状態 |
|---|---|---|
| iDeCo・退職金シリーズ | 3〜5本予定 | 第1弾完成（TICKET-005）、第2弾制作中（TICKET-006） |

### シリーズ設計のルール
- 各動画のエンディングで次回予告を入れる（視聴者の継続視聴を促す）
- タイトルにシリーズ番号は入れない（単体でも検索に引っかかるよう独立したタイトルにする）
- 1シリーズ最大5本（それ以上は視聴者が飽きるリスク）

---

## Plannerが企画を出すときの調査義務

毎回、以下を確認してから企画を作成する：

1. **YouTube検索**：同ジャンルで直近1ヶ月以内にバズった動画のタイトル・サムネを確認
2. **制度・時事チェック**：税制改正・給付金・年金制度の最新ニュースを確認
3. **FPブリーフ参照**：直近のFPブリーフから深層情報を引用する

---

## Criticの差し戻し対応ルール

| 判定 | 対応 |
|---|---|
| REVISE | Plannerが48時間以内に修正版を再提出。Criticが再審査 |
| REJECT | Plannerが新テーマで企画を作り直し。FPブリーフから再スタート |
| CONDITIONAL | 修正指示を添えて社長承認①へ。社長が最終判断 |

- 制作本数・投稿本数

- CTR・視聴維持率の平均
- Criticの差し戻し率（品質指標）
- 翌月の企画方針（FPと連携）
