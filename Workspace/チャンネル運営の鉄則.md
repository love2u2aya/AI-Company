# チャンネル運営の鉄則（全動画・例外なし）

**制定日**: 2026-10-16
**制定者**: 社長
**参考動画**: https://youtu.be/bStza7wEbWY
**管理者**: 秘書（全メンバーへの周知・遵守チェック）

> この5つは「やれたらやる」ではなく **全動画で必ずやる**。
> 1つでも抜けていたら QC は FAIL、秘書は公開を止める。

---

## 鉄則① タイトルは「今の流行り」に乗せる

| 項目 | ルール | 担当 |
|---|---|---|
| 流行りタイトル調査 | 企画を出す前に、同ジャンルで **直近2週間以内に伸びている動画のタイトル** を最低10本確認する | Planner |
| 型の抽出 | 伸びているタイトルの「言い回し・数字の使い方・語尾・記号（｜【】？！）」を型として抜き出す | Planner |
| タイトル案への反映 | タイトル案3本のうち **最低2本は流行りの型を使う**（残り1本は検索キーワード重視の王道型） | Planner |
| ストック化 | 抽出した型は `AgentOutput/タイトル流行りストック_YYYYMM.md` に毎週追記する | SNS_Manager（週次リサーチ時） |
| 審査 | Critic は「軸3：タイトル訴求力」で流行りの型を使っているかを確認する | Critic |

**守ること**
- 流行りの型に乗せても、中身と違う「釣りタイトル」はNG（視聴維持率が落ち、低評価・離脱の原因になる）
- メインキーワード（NISA・iDeCo・年金・退職金など）は必ずタイトル前半に入れる

## 鉄則② コメントにはしっかり答える

| 項目 | ルール | 担当 |
|---|---|---|
| 返信対象 | **すべてのコメントに返信する**（スパム・誹謗中傷を除く） | SNS_Manager |
| 返信の速さ | 公開後 **2時間は張り付いて即レス**。その後は24時間以内に返信 | SNS_Manager |
| 返信の質 | 「ありがとうございます」だけで終わらせない。**相手のコメント内容に具体的に触れる＋一言プラス情報 or 問いかけ** で返す | SNS_Manager |
| 金融の質問 | 制度・数字に関する質問は FP に確認してから返す（誤情報NG） | SNS_Manager → FP |
| ネタ化 | 質問・要望は `AgentOutput/コメント要望ストック_YYYYMM.md` に記録し Planner の企画ネタにする | SNS_Manager → Planner |

詳細手順：`Organization/SNS_Manager/Skills/コメント返信運用.md`

## 鉄則③ 固定コメントを必ず置く

| 項目 | ルール | 担当 |
|---|---|---|
| 設置タイミング | **公開と同時（18:00）に投稿・固定** する | SNS_Manager |
| 作成 | 固定コメント文案はメタデータ草案と一緒に作成し、QC のチェックを通す | SNS_Manager → QC |
| 中身 | ①動画の要点3行まとめ ②視聴者への問いかけ（コメントしやすい質問） ③関連動画への誘導 ④収録時点・免責 | SNS_Manager |
| 更新 | 制度改正・数値更新時は追記して延命する（既存ルールを継続） | SNS_Manager |

詳細手順：`Organization/SNS_Manager/Skills/固定コメント運用_ロングテール延命.md`

## 鉄則④ 投稿は毎回18:00

| 項目 | ルール | 担当 |
|---|---|---|
| 公開時刻 | **18:00（日本時間）固定**。曜日に関係なく必ず18:00に予約公開する | SNS_Manager |
| 予約設定 | 社長承認後、YouTube Studio の「スケジュール設定」で当日または翌日の18:00に予約する | SNS_Manager |
| 締め切り | 18:00公開に間に合わせるため、**社長承認②は当日15:00まで** に取る。間に合わない場合は翌日18:00に回す（時間をずらして公開しない） | 秘書 |
| 公開直後 | 18:00〜20:00 は SNS_Manager がコメント対応に張り付く（鉄則②） | SNS_Manager |

> 毎日同じ時間に出すことで、視聴者に「18時になったら新しい動画が出るチャンネル」と覚えてもらう。

## 鉄則⑤ 公開直後90分の動きを見る

| 項目 | ルール | 担当 |
|---|---|---|
| 監視時間 | **18:00〜19:30 の90分間**、YouTube Studio のリアルタイム数値を見続ける | SNS_Manager |
| 見る数字 | ①再生数（30分・60分・90分時点） ②Studioの「通常の動画との比較順位」（例：3/10） ③インプレッションのクリック率（CTR、表示されていれば） | SNS_Manager |
| 比較の基準 | 直近10本の「公開90分時点の再生数」の中央値（`初速記録.md` に毎回蓄積） | SNS_Manager |
| 19:30 判定 | 下の判定表で「好調／普通／不調」を決める | SNS_Manager |
| 不調のとき | **予備サムネイルに差し替え** → 差し替えから90分後（21:00）に再判定 | SNS_Manager → 秘書に報告 |
| 予備サムネ | Designerの本番案2〜3案のうち、社長承認②で **2番手** に選んだものを予備として事前に確定しておく | Designer / 社長 |
| 記録 | 毎回の数字と判定を `AgentOutput/初速レポート_YYYYMMDD.md` に残し、`初速記録.md` に追記 | SNS_Manager |

### 19:30 判定表（暫定）

| 判定 | 条件 | 対応 |
|---|---|---|
| 好調 | 90分再生数が基準の120%以上、または比較順位が1〜3位 | 何もしない。コメント対応を続ける |
| 普通 | 基準の80〜120% | 何もしない。24時間後に再チェック |
| 不調 | 基準の80%未満、または比較順位が8〜10位 | 予備サムネに差し替え → 21:00に再判定。それでも不調なら翌日の会議で原因分析 |

> **暫定ルール**：判定の数字（120%・80%など）とサムネ差し替えのやり方は、社長がサムネイル専用の参考動画を見たあとに正式に決める。
> 直近10本の記録がたまるまでは、あるだけの過去動画の平均を基準にする。

## 公開当日のタイムライン

```
〜15:00  社長承認②（秘書が取り付け）※採用サムネと予備サムネ（2番手）を両方決める
〜16:00  SNS_Manager：18:00予約公開を設定／固定コメント文案を最終確認
18:00    公開（予約）→ 即座に固定コメントを投稿・ピン留め
18:00〜19:30  初速監視（30分・60分・90分の数字を記録）＋全コメントに即レス
19:30    初速判定 → 不調なら予備サムネに差し替え
19:30〜20:00  コメント即レスを継続
21:00    （差し替えた場合のみ）再判定 → 秘書に報告
翌18:00まで  残りのコメントに24時間以内で返信／要望をストックに記録
```

- [ ] 固定コメントが公開と同時に固定されているか（SNS_Manager）
- [ ] 公開後24時間以内に全コメントへ返信したか（SNS_Manager）
